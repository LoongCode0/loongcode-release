## LoongCode とは

**LoongCode** は **Tauri 2 + React 19** ベースのクロスプラットフォーム・デスクトップ **Agent IDE** で、その本質は **Claude Code、OpenAI Codex など複数の Agent CLI を束ねる統一グラフィカルシェル**です（今後も対応 CLI を継続的に追加していきます）。

これまでコマンドラインの中でしか使えなかった Agent プログラミング体験を、本物の IDE スタイルのインターフェースへ持ち込みました：

- 一つひとつの「タスク」が独立した AI セッションに対応し、**Claude Code**、**OpenAI Codex** など複数の CLI を必要に応じて切り替えられます（タスクごとに個別選択、モデル / 設定はそれぞれ独立して記憶されます）。
- アプリはローカルの `claude` または `codex` CLI をサブプロセスとして起動し、ストリーミング JSON プロトコルでリアルタイムに通信します。
- イベントストリームをリアルタイムに対話 UI としてレンダリングし、同じウィンドウの中にターミナル、ファイルツリー、Git Review、コマンド / ファイルパレット、各種設定を統合しています。

> 💡 こう考えると分かりやすいでしょう：**CLI がエンジン、LoongCode がコックピット** —— モデル呼び出し・コード実行・ファイル操作は CLI に任せ、マルチタスク管理・履歴復元・Git 連携などのワークフロー強化は LoongCode が担います。両者は疎結合で動作し、それぞれ独立してアップグレードできます。

> ⚠️ **重要：LoongCode 自身はいかなるモデル API も直接呼び出しません。** すべてのモデルとのやり取りは、LoongCode が起動する CLI サブプロセスが行い、API キーとモデル設定も CLI 側で管理されます。そのため利用を始める前に、ローカル環境に**必須依存関係**を準備しておく必要があります：インストールとログインが完了した **Claude Code CLI** と **Git** です。**OpenAI Codex** ファミリーのタスクも使いたい場合は、さらに**オプション依存関係**である **Codex CLI** をインストールすれば OK です。
>
> 👉 未インストールでもアプリを離れる必要はありません：LoongCode には**「依存関係管理」**パネルが内蔵されており、Claude Code CLI、Git、Codex CLI をワンクリックで直接インストールできます（下記「システム要件」と「🧩 依存関係とワンクリックインストール」を参照）。ログインはインストール後にご自身で行ってください。

## ✨ 主な機能

### セッションとタスク
- **マルチ CLI 対応（Claude / OpenAI Codex / OpenCode / Kimi / Qoder）** —— タスクは **Claude Code**、**OpenAI Codex**、**OpenCode**、**Kimi Code**、**Qoder** など複数の CLI ファミリー間を必要に応じて切り替えられます（タスク / 下書きごとに個別選択、設定はそれぞれ独立して記憶されます）。Codex と OpenCode のタスクも、Claude と足並みを揃えたフル体験が得られます：対話の**ストリーミング出力**、**インタラクティブな承認 + グレースフルな中断**、**履歴復元**、**サブエージェントのサブカード**、**セッションフォーク**、そしてスキル / プラグイン / MCP / モデルプロバイダーのビジュアル管理。内部では Codex は `codex app-server` 経由、OpenCode は `opencode serve` + SSE イベントストリームで駆動され、新たに加わった **Kimi Code** は **ACP プロトコル**（NDJSON フレーム + JSON-RPC）経由で駆動されます —— いずれも持続的なロングコネクションとして維持され、タスク / ディレクトリごとに 1 プロセス・遅延起動・アイドル時回収という構成です。**OpenCode** は、**アプリ内モデルプロバイダーの再利用**（OpenAI 互換、config 経由で注入されるためキーの手動設定は不要）、**タスクごとの思考深度 / 権限レベル**、**worktree セッション移行**にも対応し、そのツールカードと Read 結果はいずれも Claude スタイルに統一されています。**Kimi Code** はストリーミング / 思考 / ツールカード / 承認応答 / 履歴復元 / サブエージェント対話 / 画像入力 / スラッシュコマンドパレットのいずれも Claude と足並みを揃えており、**セッション途中でのモデル / 思考深度 / 権限レベルの切り替え**に対応し、**ネイティブな Kimi OAuth ログイン**（ブラウザを自動で開くデバイスコードフロー、ログイン / ログアウト / ステータス / 使用量）と**K2.7 / K2.7 Highspeed / K3 / K3 [1m] の各モデルティア**を備え、同様に**アプリ内モデルプロバイダーの再利用**（環境変数経由で資格情報が注入されるためキーの手動設定は不要、外部プロバイダーでも思考深度は有効）にも対応し、**AskUserQuestion を Claude と同等の選択肢カードとして描画**します（選択肢をクリックして回答）。新たに加わった **Qoder** ファミリーも同じ深さで Claude に揃えています —— ストリーミング / 思考 / ツールカード / 承認 / 履歴復元 / サブエージェント対話 / セッションフォーク / ターミナル TUI モードのいずれも Claude と同じ挙動になり、**Auto（スマートルーティング）/ Ultimate / Performance / Efficient / Lite** のモデルティア、独自の思考深度（low〜max）と権限レベルピッカー、Qoder の使用量比率から導き出したコンテキスト使用量バー、**アプリ内でのネイティブ Qoder OAuth ログイン**（ブラウザを自動で開くデバイスコードフロー、Model Providers ページに表示されます）を備えています。**Codex プロバイダーは Responses API 経由で直接接続するようになりました** —— ルーティングはエンドポイントアドレスで制御され、内蔵のリレースイッチは廃止されました。
- **CLI セレクターはインストール済みの CLI のみを表示** —— CLI ファミリーのドロップダウンには、実際にマシン上に存在する CLI だけがリストアップされます（インストール検出はグローバルで、起動時とインストール完了後に自動的に更新されます）。何もインストールされていない場合は赤いヒントが表示され、ワンクリックで「依存関係管理」パネルへジャンプできます。
- **マルチワークスペース / マルチタスク管理** —— 各タスクは独立した復元可能なセッションです。タスクリストは最近のアクティビティ順に並び、使用中のタスクは自動的に上へ浮かび上がります。タスクを選択すると、その所属グループ（ワークスペース / ピン留め / タイムラインの日付バケット）が自動的に展開されフォーカスされます。サイドバーのワークスペース一覧は**ドラッグでの並べ替え**に対応しています（順序は再起動をまたいで保持され、新規ワークスペースは先頭に追加され、アプリを開き直しても並び順がシャッフルされることはありません）。
- **分割対話（マルチペイン）** —— メインエリアでは対話を複数のペインに分割できます（左右 / 上下の再帰的タイリング、分割線のドラッグ、閉じて折りたたみ、**ペインのタイトルをドラッグしてドッキング / 入れ替え・並べ替え、クリックしてインラインで名前を変更**）。各ペインは 1 つの完全な対話または新規下書きで、**ワークスペースをまたいで自由に混在**させられます。ペインを選択するとサイドバー / ファイル / ターミナル / Git が自動で追従し、レイアウトは記憶され、誤って閉じても `Ctrl+Shift+T` で取り消せます。
- **ターミナル TUI モード（ペイン単位）** —— 各ペインは対話ビューと、**ネイティブなインタラクティブ CLI TUI と同一セッションを駆動する**埋め込みターミナル（Claude / Codex / OpenCode / Kimi / Qoder のいずれにも対応 —— Kimi はほかと同様に ACP セッションを再開します）との間を切り替えられます：ターミナル側は対話が中断した地点から正確に再開し、TUI 内で生成されたターンは対話ビューに戻すとそのまま反映されます。ターミナルインスタンスはプールされているため、ペインを再分割 / 再マウントしても破棄されることはありません（スクロールバックが失われることも、画面が一瞬黒くなることもありません）。セッションがターミナル側に保持されている間は保持中バナー（「ターミナルに入る / 今すぐ終了」）が表示されるとともに送信 / フォーク / ロールバックの各操作が無効化され、2 つのモードは互いに排他的に保たれます。保持されたセッションは、出力が 10 秒間途絶えると自動的に終了します。**下書きタスクを最初にメッセージを送らずにターミナルへ直接ドロップ**することもできます —— セッション ID が事前にバインドされるため、対話ビューと TUI は常に同じセッションを共有します。そのまま何も入力せずに離れると未使用のバインドはクリーンアップされ、名前がまだ付いていないタスクは、ターミナルのターンが読み戻されると**最初のユーザーメッセージから自動的にタイトルが付けられます**。
- **対話をまたぐ深層検索** —— `Ctrl+Shift+F`（または検索ボックスのエントリ）から、**全タスクの対話履歴を横断する全文検索**（Claude、Codex、Kimi、Qoder のセッションをすべてカバーし、アーカイブ済みタスクも必要に応じて検索対象に含められます）を開けます：入力しながらデバウンス処理される検索結果はタスクごとにグループ化され、複数キーワードのハイライトとキーボード操作によるナビゲーションに対応し、ヒットした項目をクリックすると元のメッセージへ直接ジャンプして一瞬ハイライト表示されます。
- **セッション共有** —— 対話画面の中で**その場でメッセージを選択**し（全選択・リアルタイム件数表示・有効期限に対応したチェックボックス選択モード）、ワンクリックで共有リンクを発行できます。**「ツールを含める」**チェックボックスをオンにすると、共有ページにツール呼び出しのセグメントも含められます（チェックを入れるとツール行のグレーアウトが解除され、ゴーストユニットは最初のツール行を基準に配置されます）。テキストと構造化されたツールのペイロードの両方が忠実に再現されます。作成時には任意で**パスワード保護**を設定でき —— 作成完了ダイアログにはアクセスパスワードが表示され（単体でもコピー可能）、管理ダイアログではパスワード保護された共有に鍵アイコンのバッジが付き、完全なリンクのコピー / 開くにも対応します。左下のバッジから開く管理ダイアログには、これまで共有した項目が一覧表示され、コピー / 開く / 取り消し / 一括削除の操作ができます。リンクは**セルフホスト可能な共有サーバー**が配信を担い、専用の**設定 →「共有」**セクションで（サーバーアドレス + 公開キーを）設定できます。
- **タスクのアーカイブ** —— アクティブでなくなったタスクは、手動（ドロップダウン / 右クリック、または対話エリアの空白部分を右クリックして「アーカイブして閉じる」/「アーカイブして新規作成」のショートカットを使う方法も）でも、最近のアクティビティ時刻に基づく自動でもアーカイブでき、独立した「アーカイブビュー」に収納してメインリストをすっきり保てます。自動アーカイブは設定でオン / オフとしきい値（時間 / 日 / 月）を調整でき、実行中 / ピン留めのタスクは保護されます。
- **新規タスクの下書き状態** —— 「新規」をクリックするとまず下書きに入り、ワークスペース / モデル / Git ブランチまたは worktree をインラインで選択できます。最初のメッセージを送信して初めてタスクが正式に作成されます（`Ctrl+N` でクイック作成、既定では前回使ったワークスペースが選択されます）。
- **履歴の正確な復元** —— CLI のネイティブなセッション記録（Claude の JSONL、Codex の rollout）にアプリ側の sidecar を組み合わせて対話を復元します。ユーザー入力内のファイル・コマンド・画像 chip のアイデンティティまで 1:1 で再現されます。
- **オンデマンドのセッションインポート** —— 任意のワークスペースから過去の CLI 対話をタスクとしてオンデマンドでインポートできます：5 つの CLI ファミリーすべて（Claude / Codex / OpenCode / Kimi / Qoder）のセッションをスキャンし、検索、重複マーク、ワンクリックでの一括タスク作成に対応 —— 過去のターミナルセッションを LoongCode の中でそのまま開き直して続きを再開できます。
- **セッションフォーク / グレースフルな中断 / 再実行** —— 履歴の任意のノードから新しいセッションを fork できます。「停止」のクリックは ESC によるグレースフルな中断と同等で、生成済みの内容を保持したまま対話を続けられます。
- **過去のユーザーメッセージを編集**し、その時点から続行できます。
- **サブ Agent のサブ対話** —— サブ Agent の対話は独立した折りたたみカードにルーティングされ、メインスレッドと同じバブル / プレーンテキストのビジュアル言語でレンダリングされます（委任されたタスクのトピックをタイトルにしたヘッダーカードが指示バブルへと展開し、続けてターンごとの完全なストリームが表示されます）。メインスレッドは明瞭なまま干渉しません。`SendMessage` で同じサブ Agent に再度メッセージを送ると、その場でライブストリームが再開します——すでに終了していてもカードは「実行中」に戻ります——コーディネーターが差し込んだフォローアップは指示バブルとしてインラインにレンダリングされます。`SendMessage` のツールカードにも**ターゲットへジャンプするエントリ**が追加され、対象のサブ Agent までスクロールして一時的にハイライトし、ネストされた祖先チェーンに沿って折りたたまれたカードを自動的に展開します（一番下からスクロールして離れると、フローティングの**最新へスクロール**ボタンが表示されます）。
- **バックグラウンドタスクのアクティビティ表示と閲覧** —— `run_in_background` で起動したバックグラウンドコマンド、非同期サブ Agent、サービスプロセス、**動的ワークフロー**などは、全過程がリアルタイムで見え、「実行中」のまま固まることは決してありません：タスク行と**各ペイン自身の入力ツールバー**（そのペインのタスクに紐づき、単一のグローバルなタイトルバーインジケーターではなくなりました）では **⚡N インジケーター**が件数を集約し、完了 / 失敗は個別に消せるハイライトドットで既読・未読を表現します（ポップアップも音も出しません）。**グループオーバーレイ**を開けばすべてのバックグラウンド項目を素早く確認でき（ワークフロー項目には専用アイコンと種別ヒント付き）、バックグラウンドタスクを起動したツールカードの下部には**バックグラウンドステータスバー**が追加され、**実行中でも使える「出力を見る」エントリ**が備わります（バックグラウンドサブ Agent はその場で展開してサブ対話を確認でき、ネストされたサブ Agent のリアルタイムレンダリングも含みます）。コマンド / サービス系は右側に、タスク実行中も新しい出力をストリーミングし続ける**閉じられるリアルタイムログビュー**を開くこともできます。
- **動的ワークフローの可視化（Claude / Qoder、ノンブロッキング）** —— Claude Code の動的ワークフロー（ユーザー / プロジェクトの `.claude/workflows/*.js`）と**Qoder ワークフロー**（Qoder の `transcriptDir` 読み取り経路で再構築され、ツール結果から合成された「開始」カード、スナップショットポーリング、エンベロープ展開された結果を備えたライブなリッチカードとして表示）を発見してトリガーし、実行進捗をリッチな進捗カードとしてレンダリングします：フェーズごとのグループ化（実行中は自動展開 / アイドル時は自動折りたたみ）、サブエージェントへのドリルダウンで transcript を確認、使用量と結果が一目瞭然、アプリを再起動してもディスクからカードを再構築できます。ワークフローは**全過程バックグラウンドでノンブロッキング実行**されます：実行中も入力ボックスはロックされず対話を続けられ、バックグラウンドタスク体系に統合されます（⚡ インジケーター / 未読ドット / サイドバーのタイマー / バックグラウンドアクティビティオーバーレイが同期してカバー）。長時間実行のワークフローがアイドル回収で誤って終了させられることはなく、プロセスの異常終了や手動終了も正直に失敗としてマークされます。
- **メッセージの定時実行** —— タスクに予約送信を設定できます：指定時刻 / 間隔 / 毎日 / Cron の 4 つのモードに対応し、依存関係不要の日時ピッカーを内蔵、下書き状態のタスクでも予約できます。予約状態は紫色のインジケーターで表示され、グローバル概要でまとめて確認・管理できます。
- **モバイル対応（WeChat ClawBot / Lark）** —— WeChat 公式の ClawBot または Lark ボットを連携すると、スマートフォンからリモートでタスクを新規作成 / 駆動し、AI の返信を受け取れます。インタラクティブな質問（AskUserQuestion）にも数字を返信して回答できます。Lark チャンネルは**ネイティブ Rust の持続接続**として実装されています：QR コードスキャンでアプリ連携を確立し、プライベートチャットは全転送 / グループでは @ メンションでボットをトリガー、接続ヘルスインジケーター（緑 / 黄 / グレー）を備え、ネットワークが不安定でも自動再接続し資格情報を失いません。
- **PC リモートブリッジ（モバイルコンパニオン）** —— スマートフォンで QR コードをスキャンしてデスクトップとペアリングすると、**暗号化リレー**経由でデスクトップとの信頼性の高い双方向接続を確立し、デスクトップのタスクをスマートフォンからリモートで駆動できます：対話メッセージのリアルタイム送受信、**忠実な履歴リプレイ**（ユーザーメッセージ内のリッチテキスト / 画像はスマートフォン側に戻っても表示され、各 event にはグローバルに安定した連番が付きます）、タスク単位のルーティング、グレースフルな中断に対応し、入力ボックスも **/コマンド · @ファイル · 画像**などのリッチ入力をサポートします。タスクを開くと**権威ある状態スナップショット**とアーカイブマークを取得し、実行中 / アーカイブ済みが一目で分かります。デスクトップの **4 点セット設定（モデル / 推論強度 / 権限 / CLI）は双方向同期**——ローカルの変更はアプリへプッシュバックされ、リモートの変更はデスクトップに永続化されます。**OpenCode タスクのモデル / プロバイダー / 思考深度 / 権限レベルなどの設定も、スマートフォン側での表示・変更が可能**で、スラッシュコマンド / スキルのリストも OpenCode をカバーし、いずれも**タスクで選択された CLI に厳密に追従**します（下書き状態で CLI を切り替えると、コマンド / スキル / ワークフローのリストもそれに合わせて切り替わり、Claude 基準の固定リストではなくなりました）。インタラクティブな質問と権限リクエストは**一度回答すれば双方向に同期**され、デスクトップで回答すると回答済み状態がリアルタイムでスマートフォンへ伝わり、両端で二重に催促されることはありません。**未回答の権限リクエストはタスクを開き直しても引き続き回答できます**（停止 / 中断の経路も同期してクリーンアップされ、ゴースト承認カードは残りません）。**バックグラウンドタスクと動的ワークフローも同様にリモートから見えます**——スマートフォンはバックグラウンドタスクの状態をリアルタイムに受信し、バックグラウンドサブ Agent の内部対話はアクティブなターン中にリアルタイムでストリーミングされ、アプリのコールドスタート時にディスクから再構築されたワークフロー実行はタスクを開くと同時にバックフィルされ、ワークフローのサブエージェントの transcript もリモートで確認できます。基盤は**ネイティブ Rust** 実装です：ECDH ペアリング + エンドツーエンド暗号化、切断時は自動再接続・再送信でパケットを失わず、アプリケーション層ハートビートによるキープアライブと偽オンライン検出、**画面オフ / システムスリープ時のキープアライブ**（画面が消灯している間も電源管理アサーションで接続を維持し、ウォールクロックのジャンプでスリープ復帰を検知することで、ブリッジとボットを数秒以内に再接続させます）を備え、デバイスの連携解除は即時に反映され、解除された App へ明確な受領通知を返します。
- **グループチャット / 複数メンバー協働** —— メンバーライブラリから AI エージェントのチームを組んで（Claude / Codex / OpenCode / Kimi / Qoder の各メンバーはファミリーごとに独自のモデル・思考深度・アイコンを持ちます）、1 つの共有対話の中で会話できます：オーケストレーターはターンをチェーン単位で直列化します（チェーン内は直列、チェーン間は並列、メンバー単位では全体として直列。派生したリレーチェーンはすでにキューイング済みのメンバーを重複排除し、**全オーケストレーターターンにメンバーロスターが注入される**ため @メンションは完全一致のフルネームに一致する必要があります）。**メンバー単位のきめ細かい緊急停止**と**グループ全体の停止**（トゥームストーンが遅延イベントを吸収）に対応し、再起動をまたいで全状態を永続化します（3 テーブルスキーマ、非表示タスクの除外、レイヤー 2 のブレインスワップ復旧）。**権限ドロップダウンは各メンバーの CLI ファミリーに適応**し（ファミリー固有の値文字列として保存されるため、codex / opencode / kimi の権限が失われることはもうありません）、ライブイベントストリームは 40ms のウィンドウでマージされて複数メンバーの並発バーストを吸収し、永続的な作成エントリがフォールバックとして表示されることで、いかなる状態でも作成エントリは常に 1 つだけ存在します。メッセージはストリーミングでセグメント化された会話として描画され、思考は専用フィールドに振り分けられ（本文に思考ノイズが混ざりません）、バブルはメンバー単位で折りたたまれツールグループの一括展開ができ、バブル内の @メンバー chip はインラインで表示され、セグメントは到着順にインターリーブされます。Composer には 2 セクション構成の @ パネル（メンバー / @all）が統合されています。グローバルな**設定 →「実験的機能」**セクションにグループチャットのトグルがあります（既定ではオフ）。

### 対話体験
- **リッチテキストのメッセージバブル** —— Markdown レンダリング、表、コードのシンタックスハイライト、Markdown プレビュー。
- **Markdown のローカルリンクと画像** —— AI メッセージ内のローカルファイルパスはインラインの**ファイル chip** として描画されます（内部の相対参照はタスクのワークスペースを基準に解決され、外部の絶対パスは専用の `stat_path` コマンドで存在確認が行われ、存在しない場合は no-op リンクへと格下げされます。Codex 形式の `path:line:col` リンクは行 / 列のサフィックスを取り除いてプレーンなファイル chip になります）。ローカルおよびリモートの画像は**バブルの内側に直接**描画されます —— クリックでライトボックスに拡大、右クリックで元画像をコピー、対話コンテキストメニューには対象の種類ごとに**画像をコピー / 外部ファイルを開く**のエントリがあります。Web でも `mailto` / `tel` でもないリンクはすべて no-op です —— クリックは完全に防止され、ローカルファイルリンクが引き起こしていたアプリのリロードがついに解消されました。
- **ツール呼び出しのタイムラインカード** —— Read / Write / Edit の diff や WebSearch の結果などを連続したタイムラインカードに集約（連続する呼び出しは左端のラインを共有し、行ごとに展開して詳細を確認できます）。一目で把握でき、場所も取りません。Codex のツール呼び出しも同様のセマンティック処理を受けます：`apply_patch` は行番号付きの Write / Edit / Delete カードに展開され、読み取り専用のシェルコマンドはヒューリスティックに認識されて Read カードとしてレンダリングされ（PowerShell / cmd / bash のラッパー形式も含む）、シェルカードには python / node などの**ランナーバッジ**が付きます —— その間も元のツール名は常に確認できます。
- **インタラクティブな質問（AskUserQuestion）** —— UI 上で選択肢を直接クリックできるほか、選択肢にホバーすると分割ペインで詳細をプレビューでき（クリックでプレビューを固定、幅の狭いパネルでは縦積みレイアウトに切り替わります）、「その他」の自由入力と**「まず相談する」エントリ**（回答前に AI と自由形式のチャットを開始でき、公式の Chat-about-this フローを踏襲）にも対応しています。未解決の承認 / 選択カードは**アプリの再起動後も保持**されます（コールドスタートスナップショット）—— タスクを開き直して回答を続けられ、ゴーストカードは残りません。
- **AI メッセージツールバー**、対話内のリンクはシステムブラウザで開き、タスク状態と未読インジケーターも備えます。

### 入力（Composer）
- **スラッシュコマンドパレット**（`/command`、**CLI ファミリーごとの組み込みカタログ** —— キュレーション済みの Claude コマンド 20 種に加えて専用の Qoder コマンド 22 種セットを収録し、説明文はインターフェース言語に追従するため、異なるファミリーで同名のコマンドが混ざり合うことはありません。パレットは**ワークスペースレベルのスキル**も正しいスコープバッジ付きで拾い上げ、プラグインのインストール / アンインストール直後に即座に更新されます）と **@ ファイルメンションパレット**、インラインのファイル chip。
- **画像入力**、**タスクごとの独立した下書き**、**モデル / 推論強度セレクター**（Claude ログインでは **Fable** / Opus / Sonnet / Haiku の各ティアを内蔵。Codex ログインでは **Codex OAuth** ネイティブティアと minimal～xhigh の推論強度を内蔵。OpenCode はアプリ内の **OpenAI 互換プロバイダー**を再利用し、タスクごとに思考深度を選択可能。Kimi ログインでは Kimi OAuth 経由のネイティブ **K2.7 / K2.7 Highspeed / K3 / K3 [1m]** ティアを内蔵し、アプリ内プロバイダーの再利用にも対応。Qoder は **Auto / Ultimate / Performance / Efficient / Lite** の各ティアを独自の推論強度ピッカーとともに内蔵。モデルのドロップダウンは現在の CLI ファミリーでフィルタリングされます）、カスタマイズ可能な入力ツールバー。
- **IME セーフな chip と拡大可能な画像 chip** —— 中国語 / 日本語 / 韓国語を**chip のすぐ隣で入力**しても、IME の変換が崩れたり文字が飲み込まれたりしなくなりました：ゼロ幅の描画アンカーとキャレットのクランプにより、カーソルはすべての chip の安全な側に保たれ、コピーしたテキストにゼロ幅文字が紛れ込むこともありません。画像 chip は正方形のサムネイルとして表示され、**クリックで拡大**でき、削除 ✕ が角丸コンテナにクリップされることもなくなりました。
- **音声操作（実験的、既定ではオフ）** —— 下書きペインは**音声モード**に切り替えられます（中央寄せレイアウトは維持され、タスクは最初の音声メッセージを送信したときにのみ作成されます）。ウェイクワードの **「小馬（Xiǎo Mǎ）」**（既定値。一般的な IME と同じファジー集合によるファジーピンイン照合に対応）を発話すると音声によるウェイク応答が返ります。音声入力はオンデバイス STT（whisper、言語自動検出）で文字起こしされ、通常のメッセージとしてルーティングされます —— 選択肢カードや承認カード、複数選択の質問にも音声で回答できます。返答はローカルの TTS エンジン（Kokoro / Melo / Matcha の中国語音声と fanchen-C / aishell3 のピュア中国語音声、ONNX マルチスレッド推論）で読み上げられ、コードブロックや表をスキップするストリーミング文分割、TTS がマイクにフィードバックしないエコーフィルタリング、返答カードや承認カードの読み上げ、完了バーのリプレイボタンを備えます。音声メッセージは**オーディオバブル（AudioChip）**として描画され、右クリックメニューで文字起こしの展開、内容のコピー、テキストの非表示ができます。すべては専用の**設定 →「音声」**ページ（ウェイクワード / 無音タイムアウト / モデルのダウンロード / 音声と速度 / マスタースイッチ）で設定し、グローバルな**設定 →「実験的機能」**トグルの背後にゲートされています。

### 統合開発ツール
- **統合ターミナル** —— xterm.js + PTY ベースの本物のターミナル。ターミナルログ内のリンクはクリックできます（左クリックで内蔵ブラウザで開き、右クリックでシステムブラウザを呼び出すかアドレスをコピー）。
- **ファイルツリーサイドバー + サイドファイルパネル + Monaco エディター** —— コードと Diff の閲覧・表示。
- **リッチなファイルプレビュー** —— サイドパネルはコード以外の 10 種類以上のファイル形式をネイティブにレンダリングします：Office 文書（Word / PowerPoint / Excel）と PDF、CSV / JSONL / Parquet / SQLite をソート可能なテーブルとして表示、画像（AVIF / ICO を含む）と音声 / 動画（asset プロトコル経由でストリーミング）、アーカイブの中身（zip / jar / tar / gz、展開せずに閲覧可能）、任意のバイナリ用 Hex ビューアー、フォントの見本表示、SVG（レンダリング / ソース切り替え）、Jupyter Notebook。**Excel（.xlsx）はセルのインライン編集に対応**（セルをダブルクリック、数式セルは保護、未保存の編集はマーク表示）しており、プレビュー中の任意のファイルは**システムの既定アプリで開く**こともできます。
- **ファイルツリーの複数選択とファイル操作** —— クリックで選択 / ドラッグで矩形選択、コピー / 切り取り / 貼り付け（システムのファイルクリップボードと連携し、エクスプローラーと相互運用できます）、新規作成 / 名前変更 / 削除に対応し、`Del` と `Ctrl+C/X/V` のショートカットが使えます。
- **Git ワークフロー** —— ブランチ切り替え、変更 Review パネル、コミットメニュー（✨ ワンクリックのコミットメッセージ生成を含む）、worktree の自動検出と追従。下書きタスクには**「新しい Worktree」オプション**が用意されています：最初に worktree が作成され（`wt-` プレフィックスで自動命名され、`.git/info/exclude` に登録されるためリポジトリを汚しません）、その後にタスクがバインドされます。ファイルタブは物理的な絶対パスで重複排除され、ブレッドクラムには実際の worktree パス（`.codex/worktrees/<n>/…`）が表示され、ファイル chip はタスク自身の worktree ルートを基準に相対パスを解決します。
- **内蔵ブラウザパネル** —— 右側のパネルで Web ページを直接開けます。マルチタブ対応・タスク間共有で、ドキュメントの確認やページのプレビューにアプリを離れる必要はありません。
- 現在のワークスペースを**ファイルエクスプローラーで開く**。

### 設定と拡張
- **Skills（スキル）/ MCP サーバー / Plugins（プラグイン）/ サブエージェント（Subagents）** のビジュアル管理 —— **Claude / Codex / OpenCode / Kimi / Qoder** の 5 つの CLI ファミリーすべてをカバーします（OpenCode は元々 Claude のスキルルートを共有しており、マネージドな `opencode.json` を通じて MCP と、スキル / サブエージェント / スラッシュコマンドの有効・無効を管理します。Kimi は専用のスキルスキャン機能を持ち、ユーザー / ワークスペース両レベルの MCP `mcp.json` の作成・参照・更新・削除に対応して変更時にはサブプロセスが自動的に再起動され、**マーケットプレイスからのプラグインインストール**にも対応してインストール / アンインストール / 有効化 / 無効化が即座に反映され、サブエージェントは `AGENTS.md` で管理されます。**Qoder** はスキル / プラグイン / サブエージェント / MCP の各パネルに独自のタブを持ち、すべてその `~/.qoder` ルートに振り向けられるため、Claude の設定に混ざり込むことはありません）。サブエージェントは**ユーザー / プロジェクト / プラグイン**の 3 スコープにわたる表示・新規作成・編集・削除・有効 / 無効切り替えに対応します（プラグイン提供のものは読み取り専用）。
- **メモリ管理** —— 専用の**設定 →「メモリ」**パネルで、各 CLI の永続的な指示ファイルをアプリを離れずに一覧・プレビュー・編集・新規作成・削除できます：Claude の `CLAUDE.md` と Codex / OpenCode / Kimi / Qoder の `AGENTS.md`（グローバル・プロジェクト単位の両方）、さらに Claude の**自動メモリ（auto-memory）**トピックファイルも、検索可能で自由に命名できるコレクションとして表示されます。
- **Hooks（フック）設定** —— Claude、Codex、Kimi、Qoder のライフサイクルフック（ツール呼び出しの前後、セッション開始 / 終了など）を UI 上でそのまま表示・追加・編集・削除できます —— Claude と Qoder のユーザー / プロジェクト共有 / プロジェクトローカルの `settings.json` 各層（Qoder は独自の `.qoder` ルートの下）と Codex / Kimi の `config.toml` をカバーし、既知のフィールドには構造化フォームを使用します（認識できない項目は raw テキストにフォールバック）。さらに、プラグインや管理ポリシーが提供するフックを集約した読み取り専用ビューも備えます。
- **Model Providers（モデルプロバイダー）** の設定で、バックエンドを自由に切り替え —— 一般的なモデルには**コンテキストウィンドウの出荷時デフォルト値**が内蔵されており、モデルを追加するときは入力ボックスのプレースホルダーが推奨値を直接提示します（空欄のままでも妥当なデフォルトが使われます）。各プロバイダーは**ネットワークプロキシ**（システムに従う / カスタム / オフ）を個別に設定でき、CLI ログインに依存するプロバイダー（例：Codex OAuth リレー、あるいはブラウザでデバイスコードページを開く **Qoder OAuth** 行）はアプリ内で**ログイン / ステータス / ログアウト**のフローを利用でき、ログインコマンドは編集可能で、モデルカタログのワンクリック更新にも対応します。
- **依存関係管理 + ランタイムバージョン管理** —— 依存関係は静的なカタログから即座にレンダリングされ（各項目のインストール状態はバックグラウンドで遅延検出されます）、必須 / オプションの層に分けて表示されます。**必須依存関係の Claude Code CLI と Git はアプリ内ワンクリックインストールに対応**（Windows では直接インストール、macOS の Git はシステムの Xcode コマンドラインツールへ誘導）し、**OpenAI Codex、OpenCode、Qoder CLI もアプリ内でワンクリックインストール / 更新可能**です（3 つの AI CLI のうち少なくとも 1 つをインストールすれば十分です）。`uv` / `pnpm`（および `bun`）については複数バージョンの一覧表示 / インストール / アンインストール / 切り替えができ、ワンクリックのフォールバックインストールにも対応します。
- **プロキシ設定** —— 単一のグローバルスイッチではなく、モデルプロバイダーごとに設定します（前述のとおり）。対応するのは http / https のみです（SOCKS は非対応）。依存関係のダウンロード（CLI インストーラー、`uv` / `pnpm` / `bun`）はデフォルトでシステムのプロキシに従い、依存関係ごとに個別上書きも可能です。
- **環境変数設定** —— CLI サブプロセス（Claude / Codex）にカスタム環境変数を注入できます（変更は自動的にサブプロセスの再起動をトリガーします）。
- **使用量統計（Usage）** —— 消費状況を直感的に確認できます。Claude または Codex OAuth でログイン済みなら、リアルタイムの使用量バッジ（セッション / 週間パーセンテージ、5 分ごとに更新）がサイドバーとプロバイダーのログインカードに表示されます（Codex の使用量表示は実験的トグルによるオプトイン）。統計は現在**4 つの CLI ファミリーすべて（Claude / Codex / Kimi / Qoder）**を対象としており、CLI 単位で切り替え可能な軸を備えた動的カラーのチャートとモデルテーブル（12 のキュレーション済みカラー + 黄金角オーバーフロー、テーマに合わせて調整）で表示されます。また、**キャッシュトークンが分離されました**：モデルテーブルには合計 / 入力 / 出力 / キャッシュの列がバイリンガルラベル付きで追加され、合計トークンカードにはキャッシュヒット率の副次行が表示され、モデルごとのヒット率はキャッシュヒットに追従し、ランキングは合計順にソートされます（リレー / 中間者セッションも Codex の使用量に計上されます）。**ヒートマップのセル（日次）**や**トレンドのポイント（モデル単位）**にホバーすると入力 / 出力 / キャッシュヒットの内訳が表示され、合計トークンカード、ヒートマップ、日次トレンドはいずれも**キャッシュ読み取りをカウント**し、すべての数値がモデルテーブルの列と一貫します。**グローバルなアカウント使用量スイッチ**（「設定 → 一般」）をオフにすると、機能全体を一括で無効化できます：サイドバーのバッジは完全に非表示になり、バックグラウンドのポーリングと手動更新もすべて停止し、プロバイダーカードの使用量ブロックには無効化されている旨のヒントが表示されます —— 即座に反映され、再起動は不要です。macOS では、バックグラウンドでの使用量 / OAuth ステータスチェックによって、システムの「他の App のデータへのアクセスを求めています」権限ポップアップが表示されることはもうありません。

### デスクトップ体験
- **アプリ全体のカスタム右クリックメニュー** —— 対話エリア、プレビュー、ファイルツリー、タスク行、サイドバーの空白部分に、それぞれの場面に合った右クリックメニューを用意し、システム標準のメニューを置き換えます。
- **バックグラウンドのタスクバー通知** —— ウィンドウが前面にないとき（最小化を含む）、AI の完了 / 失敗 / 確認リクエストのポップアップがあると、QQ / WeChat のようにタスクバーアイコンが点滅します。
- **新規タスクは前回の設定を記憶** —— 新規タスク / スキルは、前回使用したモデルプロバイダーとパラメーターを自動的に引き継ぎます。
- **ネイティブウィンドウ装飾（macOS）** —— macOS ではシステムネイティブの Overlay タイトルバーと 3 色（赤・黄・緑）ボタンを採用し、サイドバーのヘッダーはそのボタンの下にロゴ / ワードマークを独立した行として配置する**2 段レイアウト**を採用してネイティブ 3 ボタン用のセーフエリアを確保、ノッチ付きディスプレイのフルスクリーンセーフエリアにも対応します。Windows はボーダーレスのカスタムウィンドウを維持します。
- **テーマと配色の一貫性（宣紙墨金）** —— まったく新しい「宣紙墨金」のビジュアル言語：丁寧にチューニングされた 3 つのテーマ（ダーク / ライト / 目に優しい黛青）、温かみのある宣紙の下地 + 墨色の文字 + アクセントの金印。コンテンツ見出しには Source Han Serif（源ノ明朝）のセリフ体を採用し、ダークテーマでは背景にほのかな金色のグローを添えています。対話エリア、入力エリア（紙面のフローティングボックス + 円形金印の送信ボタン）、タスク行（金のしおり型ステータススペクトラム）、設定ページ（紙面カードのグルーピング）、ファイルパネル / ターミナル / Monaco（gruvbox ANSI16）まで、アプリ全域で一貫した装いに統一。アプリ全体の配色は統一されたテーマ token の土台（ロール / カテゴリーカラーパレット / セマンティック token、ライト・ダーク自動適応）の上に構築されており、diff、サブ Agent、Review、使用量アラート、ボット接続インジケーター、ワークフロー状態、モデルカラーパレット、タグファミリーなどの場面はすべてハードコードされた色ではなく token を参照するため、テーマをまたいでも見た目が一貫し、デフォルトでシステムのライト / ダークに追従します。
- **新アプリアイコン「ウロボロスの環龍」** —— 玄墨と金の角丸方印バッジ：尾を銜えて環をなす小さな龍が玄墨の下地に鎮座し、金の鱗がアクセント。アプリ内サイドバーのロゴは 3 テーマ（ダーク / ライト / 目に優しい黛青）に追従して切り替わり、それぞれ専用の配色で表示され、目に優しいテーマのワードマークは黛青と同色を採用しています。
- **インターフェース言語（中国語 / 英語）** —— グラフィカルインターフェース全体が中国語と英語の切り替えに対応しています。デフォルトではシステム言語に追従し、判別できない場合は英語にフォールバックします。「設定 → 一般」からいつでも切り替えられます。AI の対話内容には影響しません。
- **中国語 / 英語のインストール画面** —— インストール時に言語を選択できます。
- **概要ページ（About）** —— 専用の**設定 →「概要」**ページ：アプリ / バージョン情報、6 状態の更新チェック行、ライセンスとプライバシーポリシーの全文ページ（中国語 / 英語、インターフェース言語に追従）、スポンサーセクション（WeChat / Alipay の QR コード）、連絡先行（メールアドレスのコピー）と公式リポジトリへのリンクを備えます。
- **自動更新を内蔵** —— 起動後にサイレントにチェックし、アップグレードを促します。
- **初回ガイドツアー（Onboarding Tour）** —— 初めての利用でも迷いません。

## 📥 ダウンロードとインストール

1. 本リポジトリの **[Releases](../../releases)** ページを開きます。
2. お使いのシステムに合ったインストーラーを選んでダウンロードします：

## 🧩 依存関係とワンクリックインストール

LoongCode の実行には、2 つの**必須依存関係**が必要です：

- **Claude Code CLI** —— モデル能力を提供します（アプリ自身が Anthropic API を直接呼び出すことはありません）。
- **Git** —— ブランチ切り替え、変更 Review、worktree などの Git ワークフローを駆動します。

まだインストールしていなくても大丈夫、**手でコマンドを打つ必要はありません**：LoongCode を開いて **設定 →「依存関係管理」** に進むと、「必須依存関係」グループにそれらのインストール状態が表示されます。**「インストール」** をクリックするだけでワンクリックでセットアップ完了です。

| 必須依存関係 | Windows | macOS |
| --- | --- | --- |
| **Claude Code CLI** | ワンクリックインストール（公式インストールスクリプト） | ワンクリックインストール（公式インストールスクリプト） |
| **Git** | ワンクリックインストール（ポータブル版 PortableGit をアプリディレクトリにインストール） | 「システムインストールを起動」をクリックしてシステムの Xcode コマンドラインツールのインストールを呼び出し。`brew install git` を自分で実行しても OK |

- インストールの過程はログがリアルタイムに表示され、完了後は自動的に状態を再検出します。
- プロキシ環境では、このパネルで依存関係ごとに http / https プロキシを設定してからインストールできます。
- 「オプション依存関係」の `uv` / `pnpm` / `bun` も、ワンクリックインストールと複数バージョンの切り替えに対応しています。
- **OpenAI Codex CLI のオプション導入** —— Codex ファミリーのタスクを使いたい場合、依存関係管理は **Codex CLI のワンクリックインストール**にも対応しています（公式インストールスクリプト / GitHub 直接接続 / ミラー加速の 3 モード）。設定のスキル / プラグイン / MCP / サブエージェント各パネルには、いずれも Codex の軸が用意されています。
- **Claude Code CLI のインストール元を選択可能** —— 公式インストールスクリプト / GitHub 直接接続 / GitHub ミラー加速（ミラーのプレフィックスはカスタマイズ可能）から選べ、一部のネットワーク環境で公式ソースに到達できない場合に対応します。
- **Git のインストール元を選択可能（Windows）** —— GitHub 直接接続 / ミラー加速（ミラーのプレフィックスはカスタマイズ可能）。ポータブル版 PortableGit なら、ネットワークが制限された環境でも問題なくインストールできます。

> ⚠️ アプリにできるのは CLI を**インストールする**ところまでです。**ログインはご自身で行う必要があります**：統合ターミナルで `claude` / `codex` を実行してプロンプトに従いログインするか、**設定 →「Model Providers」** でお使いのバックエンドを設定してください。

## 🔄 自動更新

LoongCode は [Tauri Updater](https://v2.tauri.app/plugin/updater/) を内蔵しています。アプリは本リポジトリのリリースソースへ更新マニフェストを取得しに行きます：

```
https://github.com/LoongCode0/loongcode-release/releases/latest/download/latest.json
```

新しいバージョンを検出するとユーザーに通知します。Windows では passive（サイレント）インストールモードを採用しており、更新プロセスはほとんど意識せずに済みます。

## ❓ よくある質問

**Q：ローカルにまだ Claude Code CLI や Git がインストールされていません。手動でインストールする必要がありますか？**
A：いいえ。LoongCode を開いて **設定 →「依存関係管理」** に進み、「必須依存関係」で「インストール」をクリックするだけです。Windows では Claude Code CLI と Git のどちらも直接インストールできます。macOS では Git はシステムの Xcode コマンドラインツールのインストールが呼び出されます。Claude Code CLI をインストールしたら、忘れずにログインを済ませてください。

**Q：インストールしたのに対話できない / モデルの応答がまったくない？**
A：LoongCode 自体はモデル能力を持っておらず、ローカルの CLI ツールに依存しています。対応する CLI がインストール済みで、PATH に含まれ、ログインが完了していることを確認してください：Claude タスクには `claude`、Codex タスクには `codex` が必要です。

**Q：会社のネットワークでプロキシが必要な場合は？**
A：アプリの設定で http / https プロキシを設定してください。起動される CLI は http/https のみをサポートし、SOCKS には対応していない点にご注意ください。

**Q：更新チェックで新しいバージョンが見つからない？**
A：自動更新は本リポジトリ Releases の `latest.json` に依存しています。ネットワークから GitHub にアクセスできることを確認してください。

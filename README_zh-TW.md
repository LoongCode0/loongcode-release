## LoongCode 是什麼

**LoongCode** 是一個基於 **Tauri 2 + React 19** 的跨平台桌面 **Agent IDE**，本質上是 **Claude Code、OpenAI Codex 等多套 Agent CLI 的統一圖形化外殼**（後續將持續接入更多 CLI）。

它把原本只能在命令列裡使用的 Agent 程式開發體驗，搬進了一個真正的 IDE 式介面：

- 每一個「任務」對應一個獨立的 AI 會話，可在 **Claude Code**、**OpenAI Codex** 等多套 CLI 之間視需求切換（每個任務單獨選擇，模型 / 設定各記各的）；
- 應用程式以子行程方式啟動本機的 `claude` 或 `codex` CLI，透過串流 JSON 協定與其即時通訊；
- 把事件流即時渲染成對話 UI，並在同一個視窗裡整合終端機、檔案樹、Git Review、指令 / 檔案面板，以及各類設定。

> 💡 可以這樣理解：**CLI 是引擎，LoongCode 是駕駛艙** —— 模型呼叫、程式碼執行、檔案操作交給 CLI，多任務管理、歷史還原、Git 整合等工作流程增強交給 LoongCode；兩者解耦執行、各自獨立升級。

> ⚠️ **重要：LoongCode 自身不直接呼叫任何模型 API。** 所有模型互動都由它啟動的 CLI 子行程完成，API 金鑰與模型設定也由 CLI 自行管理。因此在使用前，你需要先在本機準備好**必備依賴**：已安裝並登入的 **Claude Code CLI** 與 **Git**；若想使用 **OpenAI Codex** 家族任務，再額外裝上**可選依賴** **Codex CLI** 即可。
>
> 👉 沒裝也不必離開應用程式：LoongCode 內建**「依賴管理」**面板，可直接一鍵安裝 Claude Code CLI、Git 與 Codex CLI（見下方「系統需求」與「🧩 依賴與一鍵安裝」）；登入仍需你在裝好後自行完成。

## ✨ 核心功能

### 會話與任務
- **多 CLI 支援（Claude / OpenAI Codex / OpenCode）** —— 任務可在 **Claude Code**、**OpenAI Codex**、**OpenCode** 等多個 CLI 家族之間視需求切換（每個任務 / 草稿單獨選擇，設定各記各的）。Codex 與 OpenCode 任務均獲得與 Claude 對齊的完整體驗：對話**串流輸出**、**互動式審批 + 優雅中斷**、**歷史還原**、**子智慧體子卡片**、**會話分叉**，以及技能 / 外掛 / MCP / 模型供應商的視覺化管理；底層 Codex 經 `codex app-server`、OpenCode 經 `opencode serve` + SSE 事件流持久長連線驅動，每任務 / 每目錄一行程、惰性啟動、閒置回收。新接入的 **OpenCode** 還支援**重用應用內模型供應商**（OpenAI 相容，經 config 注入免手動配 key）、**每任務思考深度 / 權限檔位**、**worktree 會話遷移**，其工具卡與 Read 結果均統一為 Claude 風格。
- **多工作區 / 多任務管理** —— 每個任務都是一個獨立、可恢復的會話；任務清單依最近活動排序，使用中的任務自動浮上來；選取任務時自動展開並聚焦其所在分組（工作區 / 置頂 / 時間軸日期桶）。
- **分割畫面對話（多分欄）** —— 主區可把對話切成多個分欄（左右 / 上下遞迴平鋪、分割線可拖曳、可關閉收合、**拖曳分欄標題可停靠 / 交換重排**），每個分欄是一個完整對話或新建草稿，可**跨工作區自由混排**；選取分欄時側邊欄 / 檔案 / 終端機 / Git 自動跟隨，版面配置會被記住，誤關可 `Ctrl+Shift+T` 復原。
- **任務封存** —— 不再活躍的任務可手動（下拉選單 / 右鍵）或依最近活動時間自動封存，收納進獨立的「封存檢視」，主清單更清爽；自動封存可在設定裡開關與調整門檻值（小時 / 天 / 月），執行中 / 置頂任務受保護。
- **新增任務草稿態** —— 點「新增」先進入草稿，就地挑選工作區 / 模型 / Git 分支或 worktree，送出首則訊息才正式建立任務（`Ctrl+N` 快捷新增，預設選上次用過的工作區）。
- **歷史精確還原** —— 從 CLI 的原生會話紀錄（Claude 的 JSONL、Codex 的 rollout）加上應用側的 sidecar 還原對話，連使用者輸入裡的檔案、指令、圖片 chip 身分都能 1:1 復原。
- **會話分叉 / 優雅中斷 / 重跑** —— 從任意歷史節點 fork 出新會話；點「停止」等價於按 ESC 優雅中斷，保留已生成內容、可繼續對話。
- **編輯歷史使用者訊息**，並從該點繼續。
- **子 Agent 子對話** —— 子 Agent 的對話被路由進獨立的摺疊卡片（頭卡 / 工作報告 / 降級流水三層漸進揭露），主線清晰、互不干擾。
- **背景任務活動指示與檢視** —— 以 `run_in_background` 執行的背景指令、非同步子 Agent、服務行程與**動態工作流程**等，全程即時可見、絕不卡在「執行中」：任務列與標題列用 **⚡N 指示燈** 彙總數量、完成 / 失敗以高亮點呈現已讀未讀（不彈窗、不出聲），點開**分組浮層**速覽所有背景項目（工作流程條目帶專屬圖示與種類提示），發起背景任務的工具卡底部追加**背景狀態條**（背景子 Agent 可就地展開看子對話，含巢狀子 Agent 即時渲染），指令 / 服務類還可在右側開啟**可關閉的即時日誌檢視**。
- **Claude 動態工作流程視覺化（非阻塞）** —— 發現並觸發 Claude Code 動態工作流程（使用者 / 專案 `.claude/workflows/*.js`），執行進度渲染成豐富進度卡：階段分組（執行中自動展開 / 閒置自動收合）、子智慧體下鑽查看 transcript、用量與結果一目了然，應用重啟後還能從磁碟重建卡片。工作流程**全程背景非阻塞執行**：執行期間輸入框不鎖定、可繼續對話，併入背景任務體系（⚡ 指示燈 / 未讀燈 / 側邊欄計時 / 背景活動浮層同步涵蓋），長時間執行的工作流程不會被閒置回收誤殺，行程異常退出或手動終止也會如實標記失敗。
- **定時執行訊息** —— 為任務設定定時傳送：支援指定時間 / 間隔 / 每日 / Cron 四種模式，內建零依賴的日期時間選擇器，草稿態任務也能預約；定時狀態以紫色指示燈呈現，可在全域總覽裡集中檢視與管理。
- **行動裝置支援（微信 ClawBot / 飛書 Lark）** —— 綁定微信官方 ClawBot 或飛書機器人後，用手機即可遠端新增 / 驅動任務、接收 AI 回覆，連互動式提問（AskUserQuestion）也能回覆數字作答。飛書通道為**原生 Rust 長連線**實作：掃碼建立應用綁定、私訊全轉發 / 群組內 @ 機器人觸發、連線健康指示燈（綠 / 黃 / 灰），網路波動自動重連且不遺失憑證。
- **PC 遠端橋接（行動裝置伴侶）** —— 用手機掃碼與桌面配對後，經**加密中繼**與桌面建立可靠的雙向連線，把桌面任務搬到手機上遠端驅動：即時收發對話訊息、**歷史保真回放**（使用者訊息裡的富文字 / 圖片切回手機端依舊可見、每則 event 附全域穩定序號）、依任務路由、優雅中斷，輸入框同樣支援 **/指令 · @檔案 · 圖片**等富輸入；開啟任務即拉取**權威狀態快照**與封存標記，執行中 / 已封存一目了然。桌面**四項設定（模型 / 推理強度 / 權限 / CLI）雙向同步**——本地改動回推 App、遠端改動回存桌面，**OpenCode 任務的模型 / 供應商 / 思考深度 / 權限檔位等設定同樣可在手機端回顯與修改**，斜線指令 / 技能清單也涵蓋 OpenCode，且**嚴格跟隨任務所選 CLI**（草稿態切換 CLI 後，指令 / 技能 / 工作流程清單隨之切換，不再固定依 Claude 列出）；互動式提問與權限請求**單點作答、雙向同步**，桌面端作答後已答狀態即時回傳手機，兩端絕不重複打擾，**待答的權限請求在重開任務時依舊可繼續作答**（停止 / 中斷路徑同步清理，不留幽靈審批卡）。**背景任務與動態工作流程同樣遠端可見**——手機端即時收到背景任務狀態、背景子 Agent 的內部對話在活躍回合內即時串流輸出，應用冷啟動時從磁碟重建的工作流程執行隨開啟任務回填、工作流程子智慧體的 transcript 遠端可查。底層為**原生 Rust** 實作：ECDH 配對 + 端對端加密、斷線自動重連重發不遺失封包、應用層心跳保活與假在線偵測，裝置解綁即時生效並向已解綁的 App 明確回執。

### 對話體驗
- **富文字訊息氣泡** —— Markdown 渲染、表格、程式碼語法高亮、Markdown 預覽。
- **工具呼叫時間軸卡片** —— Read / Write / Edit 的 diff、WebSearch 結果等聚合成連續的時間軸卡片（連續呼叫共享左緣線、可逐行展開詳情），一目了然又不佔空間。
- **互動式提問（AskUserQuestion）** —— 在 UI 裡直接點選選項，支援「其他」自訂輸入。
- **AI 訊息工具列**、對話內連結以系統瀏覽器開啟、任務狀態與未讀指示。

### 輸入（Composer）
- **斜線指令面板**（`/command`）與 **@ 檔案提及面板**、行內檔案 chip。
- **圖片輸入**、**每任務獨立草稿**、**模型 / 推理強度選擇器**（Claude 登入內建 **Fable** / Opus / Sonnet / Haiku 檔位；Codex 登入內建 **Codex OAuth** 原生檔位與 minimal～xhigh 推理強度；OpenCode 重用應用內 **OpenAI 相容供應商** 並可為每個任務選擇思考深度；模型下拉選單依當前 CLI 家族篩選）、可自訂的輸入工具列。

### 整合開發工具
- **整合終端機** —— 基於 xterm.js + PTY 的真實終端機；終端機日誌裡的連結可點擊（左鍵在內嵌瀏覽器開啟、右鍵喚起系統瀏覽器或複製網址）。
- **檔案樹側邊欄 + 側邊檔案面板 + Monaco 編輯器** —— 瀏覽、檢視程式碼與 Diff。
- **檔案樹多選與檔案操作** —— 單擊選取 / 拖曳框選，複製 / 剪下 / 貼上（串接系統檔案剪貼簿，與檔案總管互通）、新增 / 重新命名 / 刪除，支援 `Del` 與 `Ctrl+C/X/V` 快捷鍵。
- **Git 工作流程** —— 分支切換、變更 Review 面板、提交選單（含 ✨ 一鍵產生提交訊息）、worktree 自動偵測與跟隨。
- **內嵌瀏覽器面板** —— 在右側面板直接開啟網頁，支援多分頁、跨任務共享，查文件 / 預覽頁面無需離開應用程式。
- **在檔案總管中開啟**當前工作區。

### 設定與擴充
- **Skills（技能）/ MCP 伺服器 / Plugins（外掛）/ 子智慧體（Subagents）** 的視覺化管理 —— 涵蓋 **Claude / Codex / OpenCode** 三個 CLI 家族（OpenCode 天生共用 Claude 技能根目錄、經託管的 `opencode.json` 管理 MCP 與技能 / 子智慧體 / 斜線指令的啟停）；子智慧體支援**使用者 / 專案 / 外掛**三種作用域的檢視、新增、編輯、刪除與啟停（外掛提供者為唯讀）。
- **Model Providers（模型供應商）** 設定，自由切換後端 —— 常見模型內建**上下文視窗出廠預設值**，新增模型時輸入框的佔位提示直接給出建議值（留空也有合理預設）。
- **依賴管理 + 執行環境版本管理** —— 依賴依必須 / 可選分層呈現；**必備依賴 Claude Code CLI 與 Git 支援應用內一鍵安裝**（Windows 直接裝好，macOS 的 Git 走系統 Xcode 命令列工具引導），**OpenAI Codex 與 OpenCode CLI 亦可應用內一鍵安裝**（三家 AI CLI 至少裝其一即可）；對 `uv` / `pnpm`（及 `bun`）可列出 / 安裝 / 解除安裝 / 切換多版本，並支援一鍵備援安裝。
- **代理設定** —— 支援 http / https 代理（不支援 SOCKS）。
- **環境變數設定** —— 為 CLI 子行程（Claude / Codex）注入自訂環境變數（改動自動觸發子行程重啟）。
- **用量統計（Usage）** —— 直觀檢視消耗。

### 桌面體驗
- **全應用自訂右鍵選單** —— 對話區、預覽、檔案樹、任務列、側邊欄空白處都有貼合情境的右鍵選單，取代系統預設選單。
- **背景工作列提醒** —— 視窗不在前景（含最小化）時，AI 完成 / 失敗 / 跳出確認請求會像 QQ / 微信那樣閃爍工作列圖示。
- **新增任務記住上次設定** —— 新增任務 / 技能自動繼承上一次使用的模型供應商與參數。
- **原生視窗裝飾（macOS）** —— macOS 採用系統原生 Overlay 標題列與三鍵（紅黃綠）按鈕，側邊欄頂部為原生三鍵預留安全區，並支援瀏海螢幕全螢幕安全區；Windows 維持無邊框客製視窗。
- **主題化與配色一致性（宣紙墨金）** —— 全新「宣紙墨金」視覺語言：三套精心調校的主題（深色 / 淺色 / 護眼黛青），暖調宣紙底 + 墨色文字 + 金印點睛，內容性標題採用思源宋體襯線、深色主題輔以背景淡金光暈；對話區、輸入區（紙面浮盒 + 圓形金印傳送鈕）、任務列（金書籤狀態譜）、設定頁（紙面卡分組）、檔案面板 / 終端機 / Monaco（gruvbox ANSI16）全域一致換膚。全應用配色建立在統一的主題 token 地基之上（角色 / 分類色盤 / 語意 token，深淺自適應），diff、子 Agent、Review、用量警戒、機器人連線燈、工作流程狀態、模型色盤、標籤族等情境全部接入 token 而非寫死顏色，跨主題觀感一致，預設跟隨系統深淺。
- **全新應用程式圖示「銜尾圓環龍」** —— 玄墨金圓角方章徽章：銜尾成環的小龍落在玄墨底上、金鱗點睛；應用內側邊欄 logo 依三主題（深色 / 淺色 / 護眼黛青）跟隨切換、各顯專屬配色，護眼主題字標採用黛青同色。
- **介面語言（中 / 英）** —— 整個圖形介面支援中英文切換，預設跟隨系統語言、辨識不到時回退英文，可在「設定 → 一般」隨時切換；AI 對話內容不受影響。
- **中 / 英文安裝介面**，安裝時可選語言。
- **內建自動更新** —— 啟動後靜默檢查並提示升級。
- **新手導覽（Onboarding Tour）** —— 第一次使用不迷路。

## 💻 系統需求

| 項目 | 說明 |
| --- | --- |
| **作業系統** | Windows 10/11（x64 / ARM64）、macOS（Apple Silicon 與 Intel，Universal） |

| **可選依賴** | **OpenAI Codex CLI** —— 想使用 Codex 家族任務時安裝，同樣支援應用內一鍵安裝 |

## 📥 下載與安裝

1. 開啟本儲存庫的 **[Releases](../../releases)** 頁面。
2. 選擇與你的系統相符的安裝檔下載：

## 🧩 依賴與一鍵安裝

LoongCode 執行需要兩個**必備依賴**：

- **Claude Code CLI** —— 提供模型能力（應用程式本身不直接呼叫 Anthropic API）。
- **Git** —— 驅動分支切換、變更 Review、worktree 等 Git 工作流程。

本機還沒裝也沒關係，**無需手動下指令**：開啟 LoongCode，進入 **設定 →「依賴管理」**，在「必須依賴」分組裡就能看到它們的安裝狀態，點 **「安裝」** 即可一鍵裝好。

| 必備依賴 | Windows | macOS |
| --- | --- | --- |
| **Claude Code CLI** | 一鍵安裝（官方安裝腳本） | 一鍵安裝（官方安裝腳本） |
| **Git** | 一鍵安裝（可攜版 PortableGit，裝入應用程式目錄） | 點「觸發系統安裝」喚起系統 Xcode 命令列工具安裝；也可自行 `brew install git` |

- 安裝過程即時顯示日誌，完成後自動重新偵測狀態。
- 代理環境下，可在該面板為依賴單獨設定 http / https 代理後再安裝。
- 「可選依賴」`uv` / `pnpm` / `bun` 同樣支援一鍵安裝與多版本切換。
- **可選接入 OpenAI Codex CLI** —— 若想使用 Codex 家族任務，依賴管理同樣支援**一鍵安裝 Codex CLI**（官方安裝腳本 / GitHub 直連 / 鏡像加速三種模式）；設定裡的技能 / 外掛 / MCP / 子智慧體面板均提供 Codex 維度。
- **Claude Code CLI 安裝來源可選** —— 官方安裝腳本 / GitHub 直連 / GitHub 鏡像加速（鏡像前綴可自訂），因應官方來源在部分網路環境下無法連上。
- **Git 安裝來源可選（Windows）** —— GitHub 直連 / 鏡像加速（鏡像前綴可自訂），可攜版 PortableGit 在網路受限環境下也能順利裝上。

> ⚠️ 應用程式只能幫你把 CLI **裝好**，**登入仍需自行完成**：在整合終端機執行 `claude` / `codex` 依提示登入，或在 **設定 →「模型供應商」** 設定你的後端。

## 🚀 快速開始

1. **準備依賴** —— 裝好 Claude Code CLI 與 Git 並登入 CLI（想使用 Codex 家族任務再安裝 Codex CLI）；還沒裝也可以先開啟 LoongCode，到 **設定 →「依賴管理」** 一鍵安裝。
2. **安裝並開啟 LoongCode**。
3. **新增工作區** —— 指向你的專案目錄。
4. **新增任務** —— 輸入需求，按下 Enter 即開始一個會話（可在輸入欄選擇 Claude Code 或 OpenAI Codex）。
5. 在右側用**終端機、檔案樹、Git Review** 跟進改動，在設定裡視需求接入 **MCP / 外掛 / 技能 / 模型供應商**。

LoongCode 內建 [Tauri Updater](https://v2.tauri.app/plugin/updater/)。應用程式會向本儲存庫的發布來源拉取更新清單：

```
https://github.com/LoongCode0/loongcode-release/releases/latest/download/latest.json
```

偵測到新版本時會提示使用者，Windows 端採用 passive（靜默）安裝模式，更新過程幾乎無感。

## ❓ 常見問題

**Q：本機還沒安裝 Claude Code CLI 或 Git，必須手動安裝嗎？**
A：不用。開啟 LoongCode 後進入 **設定 →「依賴管理」**，在「必須依賴」裡點「安裝」即可。Windows 上 Claude Code CLI 與 Git 都能直接裝好；macOS 上 Git 會喚起系統 Xcode 命令列工具安裝。裝好 Claude Code CLI 後記得完成登入。

**Q：裝好後無法對話 / 沒有任何模型回應？**
A：LoongCode 不自帶模型能力，它依賴本機的 CLI 工具。請確認對應 CLI 已安裝、在 PATH 中並已完成登入：Claude 任務需要 `claude`，Codex 任務需要 `codex`。

**Q：公司網路需要代理怎麼辦？**
A：在應用程式設定中設定 http / https 代理。注意被啟動的 CLI 僅支援 http/https，不支援 SOCKS。

**Q：更新檢查不到新版本？**
A：自動更新依賴本儲存庫 Releases 的 `latest.json`，請確認網路可正常存取 GitHub。

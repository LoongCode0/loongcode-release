## LoongCode 是什麼

**LoongCode** 是一個基於 **Tauri 2 + React 19** 的跨平台桌面 **Agent IDE**，本質上是 **Claude Code、OpenAI Codex 等多套 Agent CLI 的統一圖形化外殼**（後續將持續接入更多 CLI）。

它把原本只能在命令列裡使用的 Agent 程式開發體驗，搬進了一個真正的 IDE 式介面：

- 每一個「任務」對應一個獨立的 AI 會話，可在 **Claude Code**、**OpenAI Codex** 等多套 CLI 之間視需求切換（每個任務單獨選擇，模型 / 設定各記各的）；
- 應用程式以子行程方式啟動本機的 `claude` 或 `codex` CLI，透過串流 JSON 協定與其即時通訊；
- 把事件流即時渲染成對話 UI，並在同一個視窗裡整合終端機、檔案樹、Git Review、指令 / 檔案面板，以及各類設定。

> 💡 可以這樣理解：**CLI 是引擎，LoongCode 是駕駛艙** —— 模型呼叫、程式碼執行、檔案操作交給 CLI，多任務管理、歷史還原、Git 整合等工作流程增強交給 LoongCode；兩者解耦執行、各自獨立升級。

> ⚠️ **重要：LoongCode 自身不直接呼叫任何模型 API。** 所有模型互動都由它啟動的 CLI 子行程完成，API 金鑰與模型設定也由 CLI 自行管理。因此在使用前，你需要先在本機準備好**必備依賴**：已安裝並登入的 **Claude Code CLI** 與 **Git**；若想使用 **OpenAI Codex** 家族任務，再額外裝上**可選依賴** **Codex CLI** 即可。
>
> 👉 沒裝也不必離開應用程式：LoongCode 內建**「依賴管理」**面板，可直接一鍵安裝 Claude Code CLI、Git 與 Codex CLI（見下方「系統需求」與「🧩 依賴與一鍵安裝」）；登入仍需你在裝好後自行完成。

## ✨ 核心功能

### 會話與任務
- **多 CLI 支援（Claude / OpenAI Codex / OpenCode / Kimi / Qoder）** —— 任務可在 **Claude Code**、**OpenAI Codex**、**OpenCode**、**Kimi Code** 等多個 CLI 家族之間視需求切換（每個任務 / 草稿單獨選擇，設定各記各的）。Codex 與 OpenCode 任務均獲得與 Claude 對齊的完整體驗：對話**串流輸出**、**互動式審批 + 優雅中斷**、**歷史還原**、**子智慧體子卡片**、**會話分叉**，以及技能 / 外掛 / MCP / 模型供應商的視覺化管理；底層 Codex 經 `codex app-server`、OpenCode 經 `opencode serve` + SSE 事件流、新接入的 **Kimi Code** 經 **ACP 協定**（NDJSON 訊框 + JSON-RPC）皆以持久長連線驅動，每任務 / 每目錄一行程、惰性啟動、閒置回收。**OpenCode** 還支援**重用應用內模型供應商**（OpenAI 相容，經 config 注入免手動配 key）、**每任務思考深度 / 權限檔位**、**worktree 會話遷移**，其工具卡與 Read 結果均統一為 Claude 風格。**Kimi Code** 則在串流、思考、工具卡、審批作答、歷史還原、子智慧體對話、圖片輸入、斜線指令面板上與 Claude 對齊，支援**會話中途切換模型 / 思考深度 / 權限檔位**，內建**原生 Kimi OAuth 登入**（裝置代碼流程，自動開啟瀏覽器；登入 / 登出 / 狀態 / 用量），涵蓋 **K2.7 / K2.7 Highspeed / K3 / K3 [1m] 模型檔位**，同樣可**重用應用內模型供應商**（經環境變數注入憑證免手動配 key，外部供應商上思考深度設定同樣生效），並將 **AskUserQuestion 渲染為 Claude 等級的選項卡片**（點選選項即可作答）。新接入的 **Qoder** 家族同樣深度對齊——串流、思考、工具卡、審批、歷史還原、子智慧體對話、會話分叉、終端機 TUI 模式皆以 Claude 的方式運作——並內建 **Auto（智慧路由）/ Ultimate / Performance / Efficient / Lite** 模型檔位、自有的思考深度（low～max）與權限檔位選擇器、依 Qoder 用量比例推算的**上下文用量條**，以及應用內**原生 Qoder OAuth 登入**（裝置代碼流程，自動開啟瀏覽器，於「模型供應商」頁面呈現）。**Codex 供應商現在經 Responses API 直連**——路由由端點位址驅動，內建的中繼開關已移除。新接入的三個家族以**實驗功能**落地（受**設定 → 實驗功能**門控，預設關閉）：**Hermes**——以 ACP 協定為基礎的家族，設定面全面打通（模型供應商、經 `AGENTS.md` 的技能與記憶、外掛、hermes 事件詞表的 hooks、經 `config.yaml mcp_servers` 的 MCP、子代理委派設定卡、LSP 伺服器偵測與逐一安裝、帶平台標籤的工具憑證與 8 平台訊息閘道），每任務 `hermes_model` / provider / provider_model 落庫持久化，**線上切換模型保留歷史**（工作階段模型存於 `state.db`，換模型後以新模型續接）、官方 `sessions export` 歷史載入、依賴偵測與 headless 一鍵安裝；以及 **Pi**——以游標為基礎的串流 JSONL 解析（消除逐行 drain 的 O(n²)）、檔案層級工作階段分叉（parentId DAG）、MCP 運作健康偵測（stdio initialize 交握 / HTTP JSON-RPC）、子 Agent 執行態生命週期卡片、三檔權限模式、套件相容升級偵測（npm `dist-tags.latest`）、用量統計接入（受實驗開關門控，camelCase usage 聚合，依 `message.id` / `promptId` 全域去重）；以及第 8 族 CLI **dsh（DeepSeek Harness）**（beta 門控）：由全域單例 `dsh web` 實例經 HTTP RPC + mux/host 雙 WebSocket 驅動（指數退避重連封頂 30s，實例死亡自動重建，工作階段落盤重啟復原），外掛清單與指令 / 功能門控狀態、agent 預設掃描（系統 / 使用者根）與預設 / 模型選擇器（模型經 RPC 從應用自身供應商注入，免手動配 key）、即時上下文注入卡與 ToolAsk 回執進歷史、自有技能根掃描進斜線指令面板 + 技能 / 記憶設定頁、子 Agent 串流工作階段事件（對齊 Claude 的 SubAgentStream 渲染）、原生三檔權限選擇器（預設 full-access）、經 RPC fork 的就地重發（session repoint 改發）。
- **CLI 選擇器只列已安裝的 CLI** —— CLI 家族下拉選單只列出本機上實際安裝的 CLI（安裝偵測為全域性，啟動時與安裝完成後皆會自動重新整理）；當一個都未安裝時，會出現紅色提示，並可一鍵跳轉到「依賴管理」面板。
- **多工作區 / 多任務管理** —— 每個任務都是一個獨立、可恢復的會話；任務清單依最近活動排序，使用中的任務自動浮上來；選取任務時自動展開並聚焦其所在分組（工作區 / 置頂 / 時間軸日期桶）。側邊欄的工作區清單支援**拖曳排序**（順序會在重啟後保留；新增的工作區固定排在最上方，重新開啟應用程式也不會打亂原有順序）。側邊欄本身重組為**「全域 / 工作區 / 任務」三分區**（預設工作區承載非工作區任務），並配備 zcode 風格的頂端操作區；全域 **Ctrl+K 搜尋** popover 自側邊欄頂端浮出——預設依名稱過濾，可勾選**深度搜尋**與**包含封存**，並依勾選狀態提供動態的空查詢提示。
- **分割畫面對話（多分欄）** —— 主區可把對話切成多個分欄（左右 / 上下遞迴平鋪、分割線可拖曳、可關閉收合、**拖曳分欄標題可停靠 / 交換重排，點擊可就地重新命名**），每個分欄是一個完整對話或新建草稿，可**跨工作區自由混排**；選取分欄時側邊欄 / 檔案 / 終端機 / Git 自動跟隨，版面配置會被記住，誤關可 `Ctrl+Shift+T` 復原。
- **終端機 TUI 模式（各分欄獨立）** —— 每個分欄都能在對話檢視與內嵌終端機之間切換，該終端機驅動的是**與原生互動式 CLI TUI 相同的一份會話**（Claude / Codex / OpenCode / Kimi / Qoder 均支援——Kimi 也像其他家族一樣接續其 ACP 會話）：終端機會從對話中斷之處精確接續，在 TUI 裡完成的輪次會在切回對話檢視時讀回顯示。終端機實例採用池化管理，重新分割 / 重新掛載分欄都不會摧毀它們（不遺失捲動歷史、不閃黑屏）；會話被終端機佔用期間會出現一條佔用提示橫幅（「進入終端機」/「立即結束」），並停用傳送 / 分叉 / 回退等入口，讓兩種模式互斥，逾時未動作的會話會在 10 秒靜默緩衝後自動結束。**草稿任務也可不先送出訊息就直接進入終端機**——session-id 預先綁定，對話檢視與 TUI 永遠共用同一份會話；不輸入任何文字就離開，未使用的綁定會被自動清理，一旦讀回終端機的輪次，尚未命名的任務會**依其首則使用者訊息自動命名**。
- **對話深度搜尋** —— `Ctrl+Shift+F`（或搜尋框入口）開啟**橫跨所有任務對話歷史的全文檢索**（Claude、Codex、Kimi 與 Qoder 會話皆涵蓋，封存任務也可依需要一併納入）：邊輸入邊以防抖節流即時出結果、依任務分組呈現，支援多關鍵字高亮與鍵盤導覽，點擊搜尋結果可直接跳至原始訊息，並以短暫定位閃爍提示所在位置。
- **會話分享** —— **就地在對話中**勾選要分享的訊息（核取方塊選取模式，支援全選、即時計數與有效期限設定），一鍵即可產生分享連結；勾選**「包含工具」**可讓分享頁面一併攜帶工具呼叫片段（工具列預設呈灰階、勾選後才轉亮，並以錨定在首則工具紀錄的佔位區塊呈現分組），忠實還原文字與結構化工具資料兩者；建立時可選擇性開啟**密碼保護**——成功對話框會顯示存取密碼（可單獨複製），管理對話框則為受保護的分享標上鎖形徽章，並可複製 / 開啟完整連結。管理對話框（由左下角徽章進入）列出所有已分享項目，提供複製 / 開啟 / 撤銷 / 全部清除等操作。分享連結由**可自架的分享伺服器**提供服務，於設定裡獨立的「分享」分頁設定（伺服器位址 + 發布金鑰）。分享匯出還會攜帶 **AskUserQuestion 問答紀錄**（tool_ask），互動式問答過程會完整呈現在分享頁上。
- **任務封存** —— 不再活躍的任務可手動（下拉選單 / 右鍵，或在對話區空白處按右鍵以快速執行「封存並關閉」/「封存並新增」）或依最近活動時間自動封存，收納進獨立的「封存檢視」，主清單更清爽；自動封存可在設定裡開關與調整門檻值（小時 / 天 / 月），執行中 / 置頂任務受保護。
- **新增任務草稿態** —— 點「新增」先進入草稿，就地挑選工作區 / 模型 / Git 分支或 worktree，送出首則訊息才正式建立任務（`Ctrl+N` 快捷新增，預設選上次用過的工作區）。
- **歷史精確還原** —— 從 CLI 的原生會話紀錄（Claude 的 JSONL、Codex 的 rollout）加上應用側的 sidecar 還原對話，連使用者輸入裡的檔案、指令、圖片 chip 身分都能 1:1 復原。冷開啟歷史任務時，對話區在歷史水合期間會顯示**載入過渡動畫**。
- **按需匯入歷史會話** —— 依需要把任一工作區的歷史 CLI 對話匯入為任務：掃描橫跨全部五個 CLI 家族（Claude / Codex / OpenCode / Kimi / Qoder）的會話，支援搜尋、重複標記與一鍵批次建立任務——舊的終端機會話可直接在 LoongCode 內重新開啟並繼續。
- **會話分叉 / 優雅中斷 / 重跑** —— 從任意歷史節點 fork 出新會話；點「停止」等價於按 ESC 優雅中斷，保留已生成內容、可繼續對話。
- **編輯歷史使用者訊息**，並從該點繼續。
- **子 Agent 子對話** —— 子 Agent 的對話被路由進獨立的摺疊卡片，採用與主線相同的氣泡 / 純文字視覺語言呈現（頭卡以委派任務的主題命名，展開後依序顯示指令氣泡與完整的逐輪串流），主線清晰、互不干擾。透過 `SendMessage` 再次傳訊給某個子 Agent，會就地恢復其即時串流——即使該子 Agent 先前已結束，卡片也會翻回「執行中」狀態；協調者注入的後續指令會以指令氣泡的形式內嵌顯示。`SendMessage` 工具卡也新增**跳至目標入口**，可捲動畫面並短暫高亮目標子 Agent，同時沿巢狀祖先鏈自動展開所有摺疊卡片；只要捲動離開底部，就會浮現一顆浮動的**捲到最新**按鈕。
- **背景任務活動指示與檢視** —— 以 `run_in_background` 執行的背景指令、非同步子 Agent、服務行程與**動態工作流程**等，全程即時可見、絕不卡在「執行中」：任務列與**各分欄專屬的輸入工具列**（範圍限定於該分欄的任務，不再是單一全域標題列指示）皆用 **⚡N 指示燈** 彙總數量、完成 / 失敗以可個別關閉的高亮點呈現已讀未讀（不彈窗、不出聲），點開**分組浮層**速覽所有背景項目（工作流程條目帶專屬圖示與種類提示），發起背景任務的工具卡底部追加**背景狀態條**，並提供**執行中也能使用的「檢視輸出」入口**（背景子 Agent 可就地展開看子對話，含巢狀子 Agent 即時渲染），指令 / 服務類還可在右側開啟**可關閉的即時日誌檢視**，任務執行期間持續串流輸出新內容。
- **動態工作流程視覺化（Claude / Qoder，非阻塞）** —— 發現並觸發 Claude Code 動態工作流程（使用者 / 專案 `.claude/workflows/*.js`）與 **Qoder 工作流程**（經 Qoder 的 `transcriptDir` 讀盤路徑重建，並以即時富卡片呈現——由工具結果組成的合成「已開始」卡、快照輪詢與解封包結果），執行進度渲染成豐富進度卡：階段分組（執行中自動展開 / 閒置自動收合）、子智慧體下鑽查看 transcript、用量與結果一目了然，應用重啟後還能從磁碟重建卡片。工作流程**全程背景非阻塞執行**：執行期間輸入框不鎖定、可繼續對話，併入背景任務體系（⚡ 指示燈 / 未讀燈 / 側邊欄計時 / 背景活動浮層同步涵蓋），長時間執行的工作流程不會被閒置回收誤殺，行程異常退出或手動終止也會如實標記失敗。
- **定時執行訊息** —— 為任務設定定時傳送：支援指定時間 / 間隔 / 每日 / Cron 四種模式，內建零依賴的日期時間選擇器，草稿態任務也能預約；定時狀態以紫色指示燈呈現，可在全域總覽裡集中檢視與管理。
- **任務看板（依賴感知自動派發）** —— 五欄看板（Planning / Pending / In Progress / Review / Done），卡片即任務：dnd-kit 跨欄拖曳與欄內排序（附移動合法性驗證）、工具列防抖搜尋 / 工作區標籤篩選 / 並發上限設定。每張卡片攜帶**完整 CLI 設定快照**（重用 ModelSelector 的模型選擇器，涵蓋全部 CLI 家族）、**依賴拓撲圖**（dagre 分層版面，唯讀 SVG，點節點開詳情）、留言區（排隊 / 已送達標記、分裂的「傳送並移動」/「僅傳送」按鈕）、依賴編輯區（搜尋新增 / chip 跳轉 / 移除，刪除需二次確認），以及**內嵌對話區**（最近訊息、待答權限提問可就地作答、跳轉分欄）。開啟卡片會 **reconcile 其 worktree**（釋出的卡片自動回退主分支），選中卡片貫通終端機 / 檔案總管 / git 面板的 worktree 根目錄，對話區依回合分組、留言點擊跳轉定位並即時更新（樂觀留言氣泡、run 結束重載），**依賴感知派發器**在並發空位出現時依 15 秒 tick 拾取 pending 卡（依賴全部 done），組裝 prompt 建立任務——in_progress 由系統託管，當機殘留自動落入 Review。
- **行動裝置支援（微信 ClawBot / 飛書 Lark）** —— 綁定微信官方 ClawBot 或飛書機器人後，用手機即可遠端新增 / 驅動任務、接收 AI 回覆，連互動式提問（AskUserQuestion）也能回覆數字作答。飛書通道為**原生 Rust 長連線**實作：掃碼建立應用綁定、私訊全轉發 / 群組內 @ 機器人觸發、連線健康指示燈（綠 / 黃 / 灰），網路波動自動重連且不遺失憑證。
- **PC 遠端橋接（行動裝置伴侶）** —— 用手機掃碼與桌面配對後，經**加密中繼**與桌面建立可靠的雙向連線，把桌面任務搬到手機上遠端驅動：即時收發對話訊息、**歷史保真回放**（使用者訊息裡的富文字 / 圖片切回手機端依舊可見、每則 event 附全域穩定序號）、依任務路由、優雅中斷，輸入框同樣支援 **/指令 · @檔案 · 圖片**等富輸入；開啟任務即拉取**權威狀態快照**與封存標記，執行中 / 已封存一目了然。桌面**四項設定（模型 / 推理強度 / 權限 / CLI）雙向同步**——本地改動回推 App、遠端改動回存桌面，**OpenCode 任務的模型 / 供應商 / 思考深度 / 權限檔位等設定同樣可在手機端回顯與修改**，斜線指令 / 技能清單也涵蓋 OpenCode，且**嚴格跟隨任務所選 CLI**（草稿態切換 CLI 後，指令 / 技能 / 工作流程清單隨之切換，不再固定依 Claude 列出）；互動式提問與權限請求**單點作答、雙向同步**，桌面端作答後已答狀態即時回傳手機，兩端絕不重複打擾，**待答的權限請求在重開任務時依舊可繼續作答**（停止 / 中斷路徑同步清理，不留幽靈審批卡）。**背景任務與動態工作流程同樣遠端可見**——手機端即時收到背景任務狀態、背景子 Agent 的內部對話在活躍回合內即時串流輸出，應用冷啟動時從磁碟重建的工作流程執行隨開啟任務回填、工作流程子智慧體的 transcript 遠端可查。底層為**原生 Rust** 實作：ECDH 配對 + 端對端加密、斷線自動重連重發不遺失封包、應用層心跳保活與假在線偵測、**螢幕關閉 / 系統睡眠保活**（電源管理斷言讓連線在螢幕關閉時依然存活，並透過系統時鐘跳變偵測喚醒，讓橋接與機器人在數秒內重新連線），裝置解綁即時生效並向已解綁的 App 明確回執。
- **群聊 / 多成員協作** —— 從成員庫組建一支 AI 智慧體團隊（Claude / Codex / OpenCode / Kimi / Qoder 成員各自依家族配備自己的模型、思考深度與圖示），在單一共用對話中交談：編排器以鏈式結構序列化輪次（鏈內串行、跨鏈並行、每個成員全域串行——衍生的轉發鏈會對已排隊成員去重，且**每輪編排都會注入完整成員名單**，@喚起必須對上精確全名），支援**細粒度的逐成員緊急停止**或**全組停止**（墓碑記號會吞掉遲到的事件），並在重啟後完整保留一切（三表結構、隱藏任務豁免、第二層腦替換復原）。**權限下拉依各成員的 CLI 家族自適應**（以家族原生值字串儲存，codex / opencode / kimi 權限不再遺失），即時事件流透過 40ms 視窗合併以吸收多成員並發突發流量，並以常駐的建立入口作為備援，確保任何狀態下都恰好只有一個建立入口。訊息以串流分段對話呈現——思考內容進入專屬欄位（主文不再有思考雜訊）、氣泡依成員收合並支援工具組批次展開、氣泡內 @ 成員 chip 行內渲染、分段依到達順序交錯顯示。Composer 整合了兩段式 @ 面板（成員 / @all）。全域性的 **設定 → 實驗功能** 區塊收納群聊開關（預設關閉）——該區塊同時收納 **Hermes** 與 **Pi** 兩個實驗 CLI 家族（全部預設關閉；Hermes 與 Pi 全關時，依賴管理面板會隱藏其摺疊分組）。

### 對話體驗
- **富文字訊息氣泡** —— Markdown 渲染、表格、程式碼語法高亮、Markdown 預覽。
- **Markdown 本機連結與圖片渲染** —— AI 訊息內的本機檔案路徑會渲染為行內**檔案 chip**（內部相對引用會對應到任務的工作區解析；外部絕對路徑會透過專屬的 `stat_path` 指令做存在性校驗，不存在時降級為無動作連結；Codex 風格的 `path:line:col` 連結形式會剝離行 / 欄後綴、變成一般檔案 chip）。本機與遠端圖片都**直接在氣泡內渲染**——點擊可放大進燈箱、右鍵可複製原始圖片，對話右鍵選單則依目標類型提供**複製圖片 / 開啟外部檔案**等項目。非網頁、非 `mailto` / `tel` 的連結一律 noop——直接阻斷點擊，徹底消除以往本機檔案連結觸發的應用程式重載刷新。**Mermaid 圖表就地渲染**——AI 訊息內的 `mermaid` 圍欄程式碼區塊會變成可點擊放大進燈箱的動態圖表，支援 PNG/SVG 匯出。
- **工具呼叫時間軸卡片** —— Read / Write / Edit 的 diff、WebSearch 結果等聚合成連續的時間軸卡片（連續呼叫共享左緣線、可逐行展開詳情），一目了然又不佔空間。Codex 的工具呼叫也採用相同的語意化處理：`apply_patch` 會展開為附行號的 Write / Edit / Delete 卡片，唯讀的 shell 指令會透過啟發式規則被辨識並渲染為 Read 卡片（涵蓋 PowerShell / cmd / bash 包裝形式），shell 卡片還會附帶執行器徽章（python / node 等）——同時仍保留原始工具名稱可見。
- **互動式提問（AskUserQuestion）** —— 在 UI 裡直接點選選項；將滑鼠停留在選項上，即可在分割面板中預覽詳情（點擊可鎖定預覽，面板較窄時會降級為堆疊版面），並支援「其他」自訂輸入與**「先討論一下」入口**（在作答前與 AI 展開自由對話，對應官方的 Chat-about-this 流程）。
- **AI 訊息工具列**、對話內連結以系統瀏覽器開啟、任務狀態與未讀指示。

### 輸入（Composer）
- **斜線指令面板**（`/command`，內建**依 CLI 家族分流的目錄**——20 條精選 Claude 指令加上專屬的 22 條 Qoder 指令集，說明文字跟隨介面語言，不同家族的同名指令不會互相混淆；面板也會以正確的作用域徽章收納**工作區層級技能**，並在外掛安裝 / 解除安裝的當下即時重新整理）與 **@ 檔案提及面板**、行內檔案 chip。
- **圖片輸入**、**每任務獨立草稿**、**模型 / 推理強度選擇器**（Claude 登入內建 **Fable** / Opus / Sonnet / Haiku 檔位；Codex 登入內建 **Codex OAuth** 原生檔位與 minimal～xhigh 推理強度；OpenCode 重用應用內 **OpenAI 相容供應商** 並可為每個任務選擇思考深度；Kimi 登入透過 Kimi OAuth 內建原生 **K2.7 / K2.7 Highspeed / K3 / K3 [1m]** 檔位，同樣可重用應用內模型供應商；Qoder 內建 **Auto / Ultimate / Performance / Efficient / Lite** 檔位並帶自有推理強度選擇器；模型下拉選單依當前 CLI 家族篩選）、可自訂的輸入工具列。
- **IME 安全的 chips 與可放大的圖片 chip** —— 緊貼 chip 輸入中 / 日 / 韓文不再破壞 IME 組字或吞字元：以零寬渲染錨點加上游標鉗制，讓游標永遠停在每個 chip 的安全側，複製的文字也不再夾帶那個零寬字元。圖片 chip 以方形縮圖呈現、**點擊即可放大**，移除的 ✕ 不再被圓角容器裁切。
- **語音互動（實驗功能，預設關閉）** —— 草稿分欄可翻入**語音模式**（保留置中版面；送出首則語音訊息才正式建立任務）。說出喚醒詞**「小碼」**（預設；以與常見 IME 相同的模糊拼音集合容錯比對）即可得到可聽見的喚醒回應；語音輸入由裝置端 STT 轉寫（whisper，自動語言偵測）並作為一般訊息路由——包括用語音作答選項 / 審批卡與多選題。回覆由本機 TTS 引擎（Kokoro / Melo / Matcha 中文音色，加上 fanchen-C / aishell3 純中文音色，ONNX 多執行緒推論）朗讀，搭配會跳過程式碼區塊與表格的串流斷句器、TTS 永不回饋進麥克風的回聲濾波、對回覆與審批卡的唸稿模式，以及完成度條重播按鈕。語音訊息以**音訊氣泡（AudioChip）**呈現，右鍵選單可展開逐字稿、複製內容或隱藏文字。一切都在專屬的**「設定 → 語音」**頁面設定（喚醒詞 / 靜默逾時 / 模型下載 / 音色與語速 / 總開關），並受全域**「設定 → 實驗功能」**開關門控。

### 整合開發工具
- **整合終端機** —— 基於 xterm.js + PTY 的真實終端機；終端機日誌裡的連結可點擊（左鍵在內嵌瀏覽器開啟、右鍵喚起系統瀏覽器或複製網址）。右側檔案面板同樣整合**終端機 tab**（常駐渲染、面板開合門控，Windows Terminal 風格標籤列——等比壓縮、溢出箭頭、浮動選中態）；側欄 / 終端機面板開合帶 **200ms 滑動動畫**。
- **檔案樹側邊欄 + 側邊檔案面板 + Monaco 編輯器** —— 瀏覽、檢視程式碼與 Diff。
- **開啟檔案外部修改即時同步** —— 開啟中的檔案 tab 透過常駐的父目錄 watcher 持續監聽磁碟（路徑過濾 + 去抖聚合）：檔案在應用程式外被修改或刪除時，tab 立即回應——跳出**外部修改衝突對話框**（載入外部版本 / 保留我的修改），Monaco 經**最小公共前後綴編輯**重載（保留游標與復原堆疊），外部刪除的檔案顯示**刪除線 tab 標記**並支援 `Ctrl+S` 一鍵重建（全域 `Ctrl+S` 兜底同樣涵蓋側邊面板預覽檔案，並透傳 worktree 路徑）。
- **豐富檔案預覽** —— 側邊面板原生渲染 10 餘種非程式碼檔案：Office 文件（Word / PowerPoint / Excel）與 PDF、CSV / JSONL / Parquet / SQLite（呈現為可排序表格）、圖片（含 AVIF / ICO）與音訊 / 影片（經 asset 協定串流播放）、封存檔內容（zip / jar / tar / gz，免解壓縮即可瀏覽）、供任意二進位檔案使用的 Hex 檢視器、字型範例、SVG（渲染 / 原始碼切換），以及 Jupyter Notebook。**Excel（.xlsx）支援就地編輯儲存格**（雙擊儲存格即可編輯，公式儲存格受保護，未儲存的修改會標示），任何預覽中的檔案都能**以系統預設應用程式開啟**。**HTML/HTM 檔案獲得內嵌即時預覽**——iframe `srcdoc` + base 注入，相對資源依檔案所在目錄解析，經遞迴 asset 目錄放行名單提供服務——並加入文字雙模式家族，每個 tab 附**編輯 / 預覽切換**（編輯為預設）。預覽還升級出 **UI 編輯模式**：注入 bridge 指令碼（預設休眠）讓渲染頁面內即可 hover / 選取 / 拖曳 / 行內編輯，浮動設定面板分內容 / 樣式 / 屬性 / HTML 四個分區，eid 衍生的修補引擎把編輯**免重新整理**直接寫回原始碼——由防抖提交流水線支撐，支援復原 / 重做。獨立 **`.mmd` / `.mermaid` 檔案**作為一等文件開啟：整檔案圖表渲染、語法高亮、PNG/SVG 匯出。
- **檔案樹多選與檔案操作** —— 單擊選取 / 拖曳框選，複製 / 剪下 / 貼上（串接系統檔案剪貼簿，與檔案總管互通）、新增 / 重新命名 / 刪除，支援 `Del` 與 `Ctrl+C/X/V` 快捷鍵。
- **Git 工作流程** —— 分支切換、變更 Review 面板、提交選單（含 ✨ 一鍵產生提交訊息）、worktree 自動偵測與跟隨。**Git 圖譜對話框**視覺化提交歷史（分頁 `git log --graph` 掃描器，90% 視口捲動分頁）——從分支彈層進入，點擊任意列展開提交詳情面板。草稿任務另有**「新增 Worktree」選項**：先建立 worktree（以 `wt-` 前綴自動命名，註冊進 `.git/info/exclude`，不會污染儲存庫），任務再綁定到它；檔案分頁依實體絕對路徑去重、麵包屑顯示真實的 worktree 路徑（`.codex/worktrees/<n>/…`），檔案 chip 則以任務自身 worktree 根目錄解析相對路徑。
- **內嵌瀏覽器面板** —— 在右側面板直接開啟網頁，支援多分頁、跨任務共享，查文件 / 預覽頁面無需離開應用程式。
- **在檔案總管中開啟**當前工作區。
- **「開啟方式」（OS 檔案關聯）** —— LoongCode 註冊為系統「開啟方式」候選（Windows NSIS 安裝程式、macOS `public.data` 文件類型）；從系統開啟的檔案進入檔案面板，應用程式已執行時會經 single-instance 轉送（轉送引數清單會過濾掉應用程式自身可執行檔）。

### 設定與擴充
- **Skills（技能）/ MCP 伺服器 / Plugins（外掛）/ 子智慧體（Subagents）** 的視覺化管理 —— 涵蓋全部五個 CLI 家族 **Claude / Codex / OpenCode / Kimi / Qoder**（OpenCode 天生共用 Claude 技能根目錄、經託管的 `opencode.json` 管理 MCP 與技能 / 子智慧體 / 斜線指令的啟停；Kimi 則有自己的技能掃描機制、使用者與工作區兩層級 MCP `mcp.json` 的增刪改查（改動自動觸發子行程重啟）、**外掛市集安裝**（安裝 / 解除安裝 / 啟用 / 停用皆即時生效），子智慧體則透過 `AGENTS.md` 管理；**Qoder** 在技能 / 外掛 / 子智慧體 / MCP 各面板都有獨立分頁，全部路由到其 `~/.qoder` 根目錄，不會與 Claude 的設定相互污染）；子智慧體支援**使用者 / 專案 / 外掛**三種作用域的檢視、新增、編輯、刪除與啟停（外掛提供者為唯讀）。
- **記憶管理** —— 設定裡新增專屬的「記憶」面板，無需離開應用程式即可列出、預覽、編輯、建立與刪除各 CLI 的持久化指令檔案：Claude 的 `CLAUDE.md` 與 Codex / OpenCode / Kimi / Qoder 的 `AGENTS.md`（均含全域與每專案層級），外加 Claude 的**自動記憶**主題檔案，以可搜尋、可自由命名的集合方式呈現。
- **Hooks 設定** —— 直接在 UI 裡檢視、新增、編輯、刪除 Claude、Codex、Kimi 與 Qoder 的生命週期 hooks（工具呼叫前 / 後、會話開始 / 結束等）——涵蓋 Claude 與 Qoder 的使用者 / 專案共用 / 專案本機三層 `settings.json`（Qoder 位於其自有 `.qoder` 根目錄下），以及 Codex / Kimi 的 `config.toml`；已知欄位提供結構化表單（無法辨識的欄位可退回原始文字編輯），外掛與受管理政策貢獻的 hooks 則另外提供唯讀彙總檢視。
- **Model Providers（模型供應商）** 設定，自由切換後端 —— 常見模型內建**上下文視窗出廠預設值**，新增模型時輸入框的佔位提示直接給出建議值（留空也有合理預設）。各供應商可獨立設定**網路代理**（跟隨系統 / 自訂 / 關閉），透過 CLI 登入驅動的供應商（例如 Codex OAuth 中繼，或會在瀏覽器中開啟裝置代碼頁面的 **Qoder OAuth** 列）則提供應用內**登入 / 狀態 / 登出**流程，登入指令可編輯，並支援一鍵重新整理模型目錄。Claude 家族供應商還可選擇呈現的**鑑權標頭**（`ANTHROPIC_AUTH_TOKEN` / `ANTHROPIC_API_KEY`），以對應環境變數注入 CLI 子行程。
- **依賴管理 + 執行環境版本管理** —— 依賴清單會從靜態目錄即時渲染（各項目的安裝狀態於背景惰性偵測），並依必須 / 可選分層呈現；**必備依賴 Claude Code CLI 與 Git 支援應用內一鍵安裝**（Windows 直接裝好，macOS 的 Git 走系統 Xcode 命令列工具引導），**OpenAI Codex、OpenCode 與 Qoder CLI 亦可應用內一鍵安裝 / 更新**（這些 AI CLI 至少裝其一即可）；對 `uv` / `pnpm`（及 `bun`）可列出 / 安裝 / 解除安裝 / 切換多版本，並支援一鍵備援安裝。
- **代理設定** —— 改為依各模型供應商個別設定（見上文），不再是單一全域開關；僅支援 http / https（不支援 SOCKS）。依賴下載（CLI 安裝程式、`uv` / `pnpm` / `bun`）預設跟隨系統代理，也可逐項覆寫。
- **環境變數設定** —— 為 CLI 子行程（Claude / Codex）注入自訂環境變數（改動自動觸發子行程重啟）。
- **用量統計（Usage）** —— 直觀檢視消耗；透過 Claude 或 Codex OAuth 登入後，側邊欄與該供應商的登入卡片上會顯示即時用量徽章（會話 / 每週百分比，每 5 分鐘重新整理一次），Codex 用量為選用功能，須透過實驗性開關開啟。統計現在涵蓋**全部四個 CLI 家族——Claude / Codex / Kimi / Qoder**——可依各 CLI 維度切換，圖表與模型表格動態配色（12 種精選色 + 黃金角溢出配色，隨主題調整），且**快取 token 已拆分**：模型表格新增總量 / 輸入 / 輸出 / 快取四欄並附雙語標籤，總 token 卡片顯示快取命中率副列、各模型命中率跟隨快取命中、排行榜以總量排序（中繼 / 中間人會話同樣計入 Codex 用量）。**懸停熱力圖儲存格（每日）**或**趨勢點（依模型）**可查看輸入 / 輸出 / 快取命中的明細，總 token 卡片、熱力圖與每日趨勢都**計入快取讀取**，讓每個數字都與模型表格的欄位一致。**全域帳號用量開關**（設定 → 一般）可一鍵關閉整個功能：側邊欄徽章會完全消失、所有背景輪詢與手動重新整理都會靜默停止，供應商卡片的用量區塊也會顯示已停用提示——即時生效、無需重啟。在 macOS 上，背景用量 / OAuth 狀態檢查不再觸發系統「想要存取其他 App 中的資料」權限彈窗。

### 桌面體驗
- **全應用自訂右鍵選單** —— 對話區、預覽、檔案樹、任務列、側邊欄空白處都有貼合情境的右鍵選單，取代系統預設選單。
- **背景工作列提醒** —— 視窗不在前景（含最小化）時，AI 完成 / 失敗 / 跳出確認請求會像 QQ / 微信那樣閃爍工作列圖示。
- **新增任務記住上次設定** —— 新增任務 / 技能自動繼承上一次使用的模型供應商與參數。
- **原生視窗裝飾（macOS）** —— macOS 採用系統原生 Overlay 標題列與三鍵（紅黃綠）按鈕，側邊欄頂部改為**兩行版面，logo / 字標獨立一行置於三鍵下方**，為原生三鍵預留安全區，並支援瀏海螢幕全螢幕安全區；Windows 維持無邊框客製視窗。
- **主題化與配色一致性（宣紙墨金）** —— 全新「宣紙墨金」視覺語言：三套精心調校的主題（深色 / 淺色 / 護眼黛青），暖調宣紙底 + 墨色文字 + 金印點睛，內容性標題採用思源宋體襯線、深色主題輔以背景淡金光暈；對話區、輸入區（紙面浮盒 + 圓形金印傳送鈕）、任務列（金書籤狀態譜）、設定頁（紙面卡分組）、檔案面板 / 終端機 / Monaco（gruvbox ANSI16）全域一致換膚。全應用配色建立在統一的主題 token 地基之上（角色 / 分類色盤 / 語意 token，深淺自適應），diff、子 Agent、Review、用量警戒、機器人連線燈、工作流程狀態、模型色盤、標籤族等情境全部接入 token 而非寫死顏色，跨主題觀感一致，預設跟隨系統深淺。
- **全新應用程式圖示「銜尾圓環龍」** —— 玄墨金圓角方章徽章：銜尾成環的小龍落在玄墨底上、金鱗點睛；應用內側邊欄 logo 依三主題（深色 / 淺色 / 護眼黛青）跟隨切換、各顯專屬配色，護眼主題字標採用黛青同色。
- **介面語言（中 / 英）** —— 整個圖形介面支援中英文切換，預設跟隨系統語言、辨識不到時回退英文，可在「設定 → 一般」隨時切換；AI 對話內容不受影響。
- **中 / 英文安裝介面**，安裝時可選語言。
- **關於頁面** —— 設定裡新增專屬的「關於」頁面：應用程式 / 版本資訊、六態的更新檢查列、完整的授權條款與隱私權政策文字頁（中 / 英文，跟隨介面語言）、贊助小節（微信 / 支付寶二維碼），以及一個聯絡列（可複製電子郵件，並附官方儲存庫連結）。
- **內建自動更新** —— 啟動後靜默檢查並提示升級。

本機還沒裝也沒關係，**無需手動下指令**：開啟 LoongCode，進入 **設定 →「依賴管理」**，在「必須依賴」分組裡就能看到它們的安裝狀態，點 **「安裝」** 即可一鍵裝好。

| 必備依賴 | Windows | macOS |

| **Claude Code CLI** | 一鍵安裝（官方安裝腳本） | 一鍵安裝（官方安裝腳本） |
| **Git** | 一鍵安裝（可攜版 PortableGit，裝入應用程式目錄） | 點「觸發系統安裝」喚起系統 Xcode 命令列工具安裝；也可自行 `brew install git` |

- 安裝過程即時顯示日誌，完成後自動重新偵測狀態。

## ❓ 常見問題

**Q：本機還沒安裝 Claude Code CLI 或 Git，必須手動安裝嗎？**
A：不用。開啟 LoongCode 後進入 **設定 →「依賴管理」**，在「必須依賴」裡點「安裝」即可。Windows 上 Claude Code CLI 與 Git 都能直接裝好；macOS 上 Git 會喚起系統 Xcode 命令列工具安裝。裝好 Claude Code CLI 後記得完成登入。

**Q：裝好後無法對話 / 沒有任何模型回應？**
A：LoongCode 不自帶模型能力，它依賴本機的 CLI 工具。請確認對應 CLI 已安裝、在 PATH 中並已完成登入：Claude 任務需要 `claude`，Codex 任務需要 `codex`。

**Q：公司網路需要代理怎麼辦？**
A：在應用程式設定中設定 http / https 代理。注意被啟動的 CLI 僅支援 http/https，不支援 SOCKS。

**Q：更新檢查不到新版本？**
A：自動更新依賴本儲存庫 Releases 的 `latest.json`，請確認網路可正常存取 GitHub。

## LoongCode란?

**LoongCode**는 **Tauri 2 + React 19** 기반의 크로스 플랫폼 데스크톱 **Agent IDE**로, 본질적으로 **Claude Code, OpenAI Codex 등 여러 Agent CLI를 하나로 묶은 통합 그래픽 셸**입니다(앞으로 더 많은 CLI가 계속 추가될 예정입니다).

명령줄에서만 쓸 수 있던 Agent 코딩 경험을 진정한 IDE 스타일 인터페이스로 옮겨 놓았습니다:

- 하나의 '작업'은 하나의 독립된 AI 세션에 대응하며, **Claude Code**, **OpenAI Codex** 등 여러 CLI 사이를 필요에 따라 전환할 수 있습니다(작업마다 개별 선택, 모델 / 설정도 각자 따로 기억);
- 앱은 로컬의 `claude` 또는 `codex` CLI를 하위 프로세스로 실행하고, 스트리밍 JSON 프로토콜로 실시간 통신합니다;
- 이벤트 스트림을 실시간으로 대화 UI로 렌더링하고, 같은 창 안에 터미널, 파일 트리, Git Review, 명령 / 파일 팔레트와 각종 설정을 통합합니다.

> 💡 이렇게 이해하면 됩니다: **CLI는 엔진, LoongCode는 조종석** — 모델 호출, 코드 실행, 파일 조작은 CLI에 맡기고, 멀티 작업 관리, 히스토리 복원, Git 통합 같은 워크플로 강화는 LoongCode가 맡습니다. 둘은 서로 분리되어 실행되며 각자 독립적으로 업그레이드됩니다.

> ⚠️ **중요: LoongCode 자체는 어떤 모델 API도 직접 호출하지 않습니다.** 모든 모델 상호작용은 LoongCode가 실행한 CLI 하위 프로세스가 수행하며, API 키와 모델 설정도 해당 CLI가 스스로 관리합니다. 따라서 사용하기 전에 로컬 머신에 **필수 의존성**을 먼저 준비해야 합니다: 설치와 로그인이 완료된 **Claude Code CLI**와 **Git**. **OpenAI Codex** 계열 작업까지 쓰고 싶다면 **선택 의존성**인 **Codex CLI**를 추가로 설치하면 됩니다.
>
> 👉 아직 설치하지 않았어도 앱을 떠날 필요는 없습니다: LoongCode에는 **'의존성 관리'** 패널이 내장되어 있어 Claude Code CLI, Git, Codex CLI를 원클릭으로 바로 설치할 수 있습니다(아래 '시스템 요구 사항'과 '🧩 의존성 및 원클릭 설치' 참고). 로그인은 설치 후 직접 완료해야 합니다.

## ✨ 핵심 기능

### 세션과 작업
- **멀티 CLI 지원(Claude / OpenAI Codex / OpenCode / Kimi / Qoder)** — 작업은 **Claude Code**, **OpenAI Codex**, **OpenCode**, **Kimi Code**, **Qoder** CLI 계열 사이를 필요에 따라 전환할 수 있습니다(작업 / 초안마다 개별 선택, 설정은 각자 따로 기억). Codex와 OpenCode 작업 모두 Claude와 동등한 완전한 경험을 얻습니다: 대화 **스트리밍 출력**, **대화형 승인 + 우아한 중단**, **히스토리 복원**, **서브 에이전트 하위 카드**, **세션 포크**, 그리고 스킬 / 플러그인 / MCP / 모델 공급자의 시각적 관리까지. 내부적으로 Codex는 `codex app-server`, OpenCode는 `opencode serve` + SSE 이벤트 스트림, 새로 추가된 **Kimi Code**는 **ACP 프로토콜**(NDJSON 프레임 + JSON-RPC)의 지속 연결로 구동되며, 작업 / 디렉터리별 1개 프로세스, 지연 시작, 유휴 시 회수 방식으로 동작합니다. **OpenCode**는 **앱 내 모델 공급자 재사용**(OpenAI 호환, config 주입으로 key를 손수 설정할 필요 없음), **작업별 사고 깊이 / 권한 등급**, **worktree 세션 마이그레이션**도 지원하며, 도구 카드와 Read 결과는 모두 Claude 스타일로 통일됩니다. **Kimi Code**는 스트리밍 / 사고 과정 / 도구 카드 / 승인 답변 / 히스토리 복원 / 서브 에이전트 대화 / 이미지 입력 / 슬래시 명령 팔레트를 Claude와 동일하게 맞췄고, **세션 중 모델 / 사고 깊이 / 권한 등급 전환**을 지원하며, **네이티브 Kimi OAuth 로그인**(브라우저를 자동으로 여는 디바이스 코드 흐름; 로그인 / 로그아웃 / 상태 / 사용량)과 **K2.7 / K2.7 Highspeed / K3 / K3 [1m] 모델 등급**을 갖췄고, 마찬가지로 **앱 내 모델 공급자를 재사용**할 수 있으며(자격 증명은 환경 변수로 주입되어 key를 손수 설정할 필요 없고, 외부 공급자에서도 사고 깊이가 반영됨), **AskUserQuestion을 Claude 수준의 선택 카드로 렌더링합니다**(옵션을 클릭해 답변). 새로 추가된 **Qoder** 계열도 그만큼 깊게 정렬되어 있습니다 — 스트리밍 / 사고 과정 / 도구 카드 / 승인 / 히스토리 복원 / 서브 에이전트 대화 / 세션 포크 / 터미널 TUI 모드가 모두 Claude 방식 그대로 동작하며, **Auto(스마트 라우팅) / Ultimate / Performance / Efficient / Lite** 모델 등급, 자체 사고 깊이(low~max) 및 권한 등급 선택기, Qoder의 사용량 비율에서 파생된 컨텍스트 사용량 바, 그리고 **앱 안에서의 네이티브 Qoder OAuth 로그인**(브라우저를 자동으로 여는 디바이스 코드 흐름, 모델 공급자 페이지에 표시됨)을 갖췄습니다. **Codex 공급자는 이제 Responses API를 통해 직접 연결됩니다** — 라우팅은 엔드포인트 주소로 결정되며 내장 릴레이 스위치는 제거되었습니다. 새로 합류한 세 계열은 **실험적 기능**으로 구현되어 있습니다(**설정 → 실험적**에서 게이트, 기본 꺼짐): **Hermes** — ACP 프로토콜 기반 계열로 설정 화면이 전면적으로 연결되어 있습니다(모델 공급자, `AGENTS.md` 경유 스킬과 메모리, 플러그인, hermes 이벤트 어휘를 쓰는 hooks, `config.yaml mcp_servers` 경유 MCP, 서브에이전트 위임 카드, LSP 서버 감지와 개별 설치, 플랫폼 라벨이 붙은 도구 자격 증명과 8-플랫폼 메시지 게이트웨이). 작업별 `hermes_model` / provider / provider_model을 영구 저장하고, **히스토리를 유지한 온라인 모델 전환**(세션 모델은 `state.db`에 저장되고 새 모델로 재개), 공식 `sessions export` 히스토리 로딩, 의존성 감지와 headless 원클릭 설치를 지원합니다. 그리고 **Pi** — 커서 기반 스트리밍 JSONL 파싱(줄 단위 drain의 O(n²) 제거), 파일 수준 세션 포크(parentId DAG), MCP 실행 상태 감지(stdio initialize 핸드셰이크 / HTTP JSON-RPC), 서브에이전트 실행 중 수명 주기 카드, 3단계 권한 모드, 패키지 호환 업그레이드 감지(npm `dist-tags.latest`), 사용량 통계 연동(실험 스위치로 게이트, camelCase usage 집계, `message.id` / `promptId` 기준 전역 중복 제거)을 갖췄습니다. 그리고 8번째 CLI 계열 **dsh(DeepSeek Harness)**(beta 게이트) — 전역 싱글턴 `dsh web` 인스턴스를 HTTP RPC + mux/host 이중 WebSocket으로 구동하며(지수 백오프 재연결, 상한 30초. 인스턴스가 죽으면 자동 재구축, 세션은 디스크에 저장되어 재시작 후 복원), 플러그인 인벤토리와 명령 / 기능 게이트 상태, 에이전트 프리셋 스캔(시스템 / 사용자 루트)과 프리셋 / 모델 선택기(모델은 앱 자체 공급자에서 RPC로 주입되어 key를 손수 설정할 필요 없음), 실시간 컨텍스트 주입 카드와 ToolAsk 영수증을 히스토리에 렌더링, 자체 스킬 루트를 슬래시 팔레트에 포함하고 스킬 / 메모리 설정 페이지도 제공, 서브에이전트 스트림은 Claude의 SubAgentStream 렌더링에 정렬, 네이티브 3단계 권한 선택기(기본 full-access), RPC fork로 그 자리에서 재전송(session repoint로 재라우팅)을 지원합니다.
- **설치된 CLI만 표시하는 CLI 선택기** — CLI 계열 드롭다운은 실제로 머신에 설치된 CLI만 나열합니다(설치 감지는 전역적으로 이루어지며 시작 시와 설치 완료 후 자동으로 새로고침됩니다). 아무것도 설치되지 않은 경우 빨간색 힌트가 나타나며 '의존성 관리' 패널로 원클릭 이동할 수 있습니다.
- **멀티 워크스페이스 / 멀티 작업 관리** — 모든 작업은 독립적이고 복원 가능한 세션입니다. 작업 목록은 최근 활동 순으로 정렬되어 사용 중인 작업이 자동으로 위로 떠오르며, 작업을 선택하면 해당 작업이 속한 그룹(워크스페이스 / 고정 / 타임라인 날짜 버킷)이 자동으로 펼쳐지고 포커스됩니다. 사이드바의 워크스페이스 목록은 **드래그 앤 드롭으로 순서를 바꿀 수 있습니다**(순서는 재시작 후에도 유지되며, 새 워크스페이스는 맨 위에 추가되고, 앱을 다시 열어도 순서가 뒤섞이지 않습니다). 사이드바 자체도 **'전역 / 워크스페이스 / 작업' 3개 섹션으로 재편**되었고(기본 워크스페이스가 비-워크스페이스 작업을 맡습니다), zcode 스타일의 상단 작업 영역을 갖춥니다. 전역 **Ctrl+K 검색** 팝오버가 사이드바 상단에서 떠오릅니다 — 기본은 이름 필터이고, **딥 검색**과 **아카이브 포함** 체크박스를 토글할 수 있으며, 체크 상태에 따른 동적 빈-쿼리 힌트를 보여줍니다.
- **분할 대화(멀티 페인)** — 메인 영역의 대화를 여러 페인으로 나눌 수 있습니다(좌우 / 상하 재귀 타일링, 분할선 드래그 가능, 닫아서 접기 가능, **페인 제목을 드래그해 도킹 / 교환 / 재배치하거나 클릭해 바로 이름 변경**). 각 페인은 완전한 대화 하나 또는 새 초안이며, **워크스페이스를 넘나들며 자유롭게 섞어 배치**할 수 있습니다. 페인을 선택하면 사이드바 / 파일 / 터미널 / Git이 자동으로 따라오고, 레이아웃은 기억되며, 실수로 닫아도 `Ctrl+Shift+T`로 되돌릴 수 있습니다.
- **터미널 TUI 모드(페인별)** — 모든 페인은 대화 화면과 내장 터미널 사이를 전환할 수 있으며, 이 터미널은 **네이티브 대화형 CLI TUI와 동일한 세션**을 그대로 구동합니다(Claude / Codex / OpenCode / Kimi / Qoder 모두 지원 — Kimi는 다른 계열과 마찬가지로 ACP 세션을 그대로 재개): 터미널은 대화가 멈춘 지점에서 정확히 이어지고, TUI 안에서 진행된 턴은 대화 화면으로 다시 전환할 때 그대로 읽어 들여집니다. 터미널 인스턴스는 풀링되어 페인을 다시 분할하거나 다시 마운트해도 파괴되지 않습니다(스크롤백 손실이나 검은 화면 깜빡임 없음). 세션을 터미널이 점유하고 있는 동안에는 점유 안내 배너('터미널로 진입 / 지금 종료')와 함께 전송 / 포크 / 롤백 항목이 비활성화되어 두 모드가 서로 배타적으로 유지되며, 점유된 세션은 10초의 무입력 드레인 윈도우가 지나면 자동으로 종료됩니다. **초안 작업은 메시지를 보내지 않고도 바로 터미널로 떨어뜨릴 수 있습니다** — 세션 id가 미리 바인딩되어 대화 화면과 TUI가 항상 하나의 세션을 공유하며, 아무것도 입력하지 않고 떠나면 사용되지 않는 바인딩이 정리되고, 아직 이름이 없는 작업은 터미널의 턴이 다시 읽혀 오면 **첫 사용자 메시지에서 자동으로 제목이 붙습니다**.
- **대화 전체 딥 검색** — `Ctrl+Shift+F`(또는 검색창 진입점)를 누르면 **모든 작업의 대화 히스토리를 전문 검색**할 수 있는 창이 열립니다(Claude, Codex, Kimi, Qoder 세션 모두 포함, 필요하면 아카이브된 작업까지 포함 가능): 입력하는 대로 디바운스 처리된 결과가 작업별로 그룹화되어 나타나고, 여러 검색어 하이라이트와 키보드 탐색을 지원하며, 결과를 클릭하면 원본 메시지로 바로 이동해 짧게 위치 표시가 깜빡입니다.
- **세션 공유** — 대화 안에서 바로 메시지를 선택하고(전체 선택, 실시간 선택 개수 표시, 유효 기간 설정을 지원하는 체크박스 선택 모드), 클릭 한 번으로 공유 링크를 발급합니다. **'도구 포함'** 체크박스를 켜면 공유 페이지에 도구 호출 구간까지 함께 담을 수 있고(체크할 때마다 도구 행이 회색에서 벗어나며, 고스트 유닛이 첫 도구 줄에 고정됨), 텍스트와 구조화된 도구 페이로드를 모두 충실하게 재현합니다. 생성 시점에 선택적으로 **비밀번호 보호**를 설정할 수 있습니다 — 성공 다이얼로그에 접근 비밀번호가 표시되고(단독 복사 가능), 관리 다이얼로그는 보호된 공유에 자물쇠 배지를 표시하며 전체 링크를 복사 / 열기 할 수 있습니다. 좌측 하단 배지로 들어가는 관리 다이얼로그는 지금까지 공유한 모든 항목을 나열하며 복사 / 열기 / 회수 / 전체 지우기를 지원합니다. 링크는 **자체 호스팅 가능한 공유 서버**가 서빙하며, 전용 설정 → 공유 섹션에서(서버 주소 + 발행 key) 구성합니다. 공유 내보내기에는 **AskUserQuestion Q&A 기록**(tool_ask)도 포함되어, 대화형 질의응답 과정이 공유 페이지에 그대로 나타납니다.
- **작업 아카이브** — 더 이상 활발하지 않은 작업은 수동(드롭다운 / 우클릭, 또는 대화 영역의 빈 공간을 우클릭해 '아카이브 후 닫기' / '아카이브 후 새로 시작' 단축 메뉴 사용)으로, 또는 최근 활동 시간에 따라 자동으로 아카이브되어 독립된 '아카이브 뷰'에 정리되므로 메인 목록이 한결 깔끔해집니다. 자동 아카이브는 설정에서 켜고 끄거나 임계값(시간 / 일 / 월)을 조정할 수 있으며, 실행 중 / 고정된 작업은 보호됩니다.
- **새 작업 초안 상태** — '새로 만들기'를 누르면 먼저 초안 상태로 들어가 워크스페이스 / 모델 / Git 브랜치 또는 worktree를 인라인으로 고르고, 첫 메시지를 보내야 작업이 정식으로 생성됩니다(`Ctrl+N`으로 빠르게 새로 만들기, 기본값은 마지막에 사용한 워크스페이스).
- **히스토리 정밀 복원** — CLI의 네이티브 세션 기록(Claude의 JSONL, Codex의 rollout)에 앱 측 sidecar를 더해 대화를 복원하며, 사용자 입력 속 파일, 명령, 이미지 chip의 정체까지 1:1로 되살립니다. 오래된 작업을 콜드 오픈하면, 히스토리가 하이드레이션되는 동안 대화 영역에 **로딩 트랜지션**이 표시됩니다.
- **온디맨드 세션 가져오기** — 모든 워크스페이스의 과거 CLI 대화를 온디맨드로 작업에 가져옵니다: 다섯 CLI 계열(Claude / Codex / OpenCode / Kimi / Qoder)의 세션을 모두 스캔하며, 검색, 중복 표시, 원클릭 일괄 작업 생성을 지원합니다 — 예전 터미널 세션을 LoongCode 안에서 그대로 다시 열어 이어서 진행할 수 있습니다.
- **세션 포크 / 우아한 중단 / 재실행** — 히스토리의 어느 지점에서든 새 세션을 fork할 수 있습니다. '중지'를 누르는 것은 ESC로 우아하게 중단하는 것과 같아서, 이미 생성된 내용은 유지되고 대화를 이어갈 수 있습니다.
- **과거 사용자 메시지를 편집**하고, 그 지점부터 이어서 진행합니다.
- **서브 Agent 하위 대화** — 서브 Agent의 대화는 독립된 접이식 카드로 라우팅되고, 메인 스레드와 동일한 버블 / 일반 텍스트 비주얼 언어로 렌더링되어(위임된 작업의 주제를 제목으로 삼는 헤더 카드가 지시 버블로 펼쳐진 뒤 턴 단위 전체 스트림이 이어지는 구조), 메인 스레드가 뒤엉키지 않고 깔끔하게 유지됩니다. `SendMessage`로 서브 Agent에 다시 메시지를 보내면 그 자리에서 실시간 스트림이 재개됩니다 — 이미 종료된 상태였더라도 카드가 다시 '실행 중'으로 바뀌며 — 코디네이터가 주입한 후속 지시는 인라인 지시 버블로 렌더링됩니다. `SendMessage` 도구 카드에는 **대상으로 이동 항목**도 추가되어 대상 서브 Agent로 스크롤 이동한 뒤 잠시 하이라이트하며, 중첩된 상위 카드 체인을 따라 접힌 카드를 자동으로 펼칩니다(하단에서 스크롤이 벗어나면 플로팅 **최신으로 이동** 버튼이 나타남).
- **백그라운드 작업 활동 표시와 확인** — `run_in_background`로 실행한 백그라운드 명령, 비동기 서브 Agent, 서비스 프로세스, **동적 워크플로** 등이 전 과정 실시간으로 보이며, '실행 중'에 멈춰 있는 일이 절대 없습니다: 작업 행과 **각 페인 고유의 입력 툴바**(해당 페인의 작업에 한정되며, 더 이상 단일 전역 타이틀 바 표시등이 아님)에 **⚡N 표시등**으로 개수를 요약하고, 완료 / 실패는 하이라이트 점으로 읽음 / 안 읽음을 표시하며 하나씩 닫을 수 있고(팝업 없음, 소리 없음), **그룹 오버레이**를 열면 모든 백그라운드 항목을 한눈에 훑어볼 수 있고(워크플로 항목에는 전용 아이콘과 종류 힌트가 붙음), 백그라운드 작업을 시작한 도구 카드 하단에는 **실행 중에도 쓸 수 있는 '출력 보기' 항목**이 딸린 **백그라운드 상태 바**가 추가되며(백그라운드 서브 Agent는 그 자리에서 펼쳐 하위 대화를 볼 수 있고, 중첩 서브 Agent도 실시간 렌더링됨), 명령 / 서비스 유형은 오른쪽에 작업이 진행되는 동안 새 출력을 계속 스트리밍하는 **닫을 수 있는 실시간 로그 뷰**를 열 수도 있습니다.
- **동적 워크플로 시각화(Claude / Qoder, 논블로킹)** — Claude Code 동적 워크플로(사용자 / 프로젝트 `.claude/workflows/*.js`)와 **Qoder 워크플로**(Qoder의 `transcriptDir` 읽기 경로로 재구성되며, 도구 결과로 합성된 '시작됨' 카드, 스냅샷 폴링, 봉투를 벗긴 결과를 담은 실시간 리치 카드 포함)를 발견하고 트리거하며, 실행 진행 상황을 리치 진행 카드로 렌더링합니다: 단계별 그룹화(실행 중 자동 펼침 / 유휴 시 자동 접힘), 서브 에이전트로 드릴다운해 transcript 확인, 사용량과 결과를 한눈에 파악할 수 있고, 앱을 재시작해도 디스크에서 카드를 재구성합니다. 워크플로는 **전 과정 백그라운드에서 논블로킹으로 실행**됩니다: 실행 중에도 입력창이 잠기지 않아 대화를 계속할 수 있고, 백그라운드 작업 체계에 편입되며(⚡ 표시등 / 안 읽음 표시 / 사이드바 타이머 / 백그라운드 활동 오버레이가 동기화되어 함께 커버), 오래 달리는 워크플로가 유휴 회수로 잘못 종료되는 일이 없으며, 프로세스가 비정상 종료되거나 수동으로 종료해도 있는 그대로 실패로 표시됩니다.
- **예약 메시지 실행** — 작업에 예약 전송을 설정할 수 있습니다: 지정 시각 / 간격 / 매일 / Cron 네 가지 모드를 지원하고, 의존성 없는 날짜·시간 선택기를 내장했으며, 초안 상태의 작업도 예약할 수 있습니다. 예약 상태는 보라색 표시등으로 나타나고, 전역 개요에서 한데 모아 확인하고 관리할 수 있습니다.
- **칸반 보드(의존성 인식 자동 디스패치)** — 5열 보드(Planning / Pending / In Progress / Review / Done)로, 카드가 곧 작업입니다: dnd-kit으로 열을 넘나드는 드래그와 열 내 정렬(이동 유효성 검사 포함), 툴바의 디바운스 검색 / 워크스페이스 태그 필터 / 동시성 상한 설정. 각 카드에는 **전체 CLI 구성 스냅샷**(ModelSelector의 모델 선택기 재사용, 모든 CLI 계열 커버), **의존성 토폴로지 그래프**(dagre 계층 레이아웃, 읽기 전용 SVG, 노드 클릭 시 상세 다이얼로그), 댓글 영역(대기 중 / 전달 완료 표시, '보내고 이동' / '보내기만' 분할 버튼), 의존성 편집 영역(검색 추가 / chip 이동 / 제거, 삭제는 재확인)과 **임베디드 대화 영역**(최근 메시지, 대기 중인 권한 질문을 그 자리에서 답변, 페인으로 이동)이 딸려 있습니다. 카드를 열면 **해당 worktree를 reconcile**하고(해제된 카드는 자동으로 메인 브랜치로 폴백), 선택한 카드가 터미널 / 파일 탐색기 / git 패널의 worktree 루트를 관통하며, 대화 영역은 턴 단위로 그룹화되고 댓글 클릭 점프·위치 찾기와 라이브 업데이트(낙관적 댓글 버블, run 종료 시 리로드)를 지원합니다. **의존성 인식 디스패처**는 동시성 슬롯에 빈자리가 생기면 15초 tick으로 pending 카드(의존성이 전부 done)를 집어 올려 프롬프트를 조립해 작업을 만듭니다 — in_progress는 시스템이 관리하고, 크래시 잔여물은 자동으로 Review로 흘러갑니다.
- **모바일 지원(WeChat ClawBot / Lark)** — WeChat 공식 ClawBot 또는 Lark 봇을 연동하면 휴대폰만으로 원격에서 작업을 새로 만들고 구동하며 AI 답변을 받을 수 있고, 대화형 질문(AskUserQuestion)에도 숫자로 답할 수 있습니다. Lark 채널은 **네이티브 Rust 지속 연결**로 구현되어 있습니다: QR 코드 스캔으로 앱 연동 생성, 개인 채팅은 전부 전달 / 그룹 채팅은 @봇 멘션으로 트리거, 연결 상태 표시등(초록 / 노랑 / 회색), 네트워크가 불안정해도 자격 증명을 잃지 않고 자동 재연결됩니다.
- **PC 원격 브리지(모바일 컴패니언)** — 휴대폰으로 QR 코드를 스캔해 데스크톱과 페어링하면 **암호화 릴레이**를 거쳐 데스크톱과 신뢰할 수 있는 양방향 연결이 수립되고, 데스크톱 작업을 휴대폰으로 옮겨 와 원격으로 구동할 수 있습니다: 대화 메시지 실시간 송수신, **히스토리 충실 재생**(사용자 메시지 속 리치 텍스트 / 이미지는 휴대폰으로 돌아가도 그대로 보이고, 모든 event에 전역적으로 안정적인 시퀀스 번호가 붙음), 작업별 라우팅, 우아한 중단을 지원하며, 입력창도 **/명령 · @파일 · 이미지** 같은 리치 입력을 그대로 지원합니다. 작업을 열면 **권위 있는 상태 스냅샷**과 아카이브 표시를 가져와 실행 중 / 아카이브됨이 한눈에 들어옵니다. 데스크톱의 **4종 구성(모델 / 추론 강도 / 권한 / CLI)은 양방향으로 동기화**됩니다 — 로컬 변경은 App으로 되밀리고 원격 변경은 데스크톱에 저장되며, **OpenCode 작업의 모델 / 공급자 / 사고 깊이 / 권한 등급 등 설정도 휴대폰에서 그대로 표시하고 수정할 수 있고**, 슬래시 명령 / 스킬 목록도 OpenCode를 포함하며, **작업이 선택한 CLI를 엄격히 따릅니다**(초안 상태에서 CLI를 전환하면 명령 / 스킬 / 워크플로 목록도 함께 전환되어, 더 이상 Claude 기준으로 고정 표시되지 않습니다). 대화형 질문과 권한 요청은 **한 곳에서 답하면 양방향으로 동기화**되어, 데스크톱에서 답하면 답변 완료 상태가 실시간으로 휴대폰에 전달되므로 양쪽에서 중복으로 묻는 일이 없고, **답변 대기 중인 권한 요청은 작업을 다시 열어도 이어서 답할 수 있습니다**(중지 / 중단 경로도 동기화되어 정리되므로 유령 승인 카드가 남지 않습니다). **백그라운드 작업과 동적 워크플로도 원격에서 똑같이 보입니다** — 휴대폰이 백그라운드 작업 상태를 실시간으로 수신하고, 백그라운드 서브 Agent의 내부 대화가 활성 턴 동안 실시간으로 흘러나오며, 앱 콜드 스타트 시 디스크에서 재구성된 워크플로 실행은 작업을 여는 순간 채워지고, 워크플로 서브 에이전트의 transcript도 원격에서 조회할 수 있습니다. 하부 구현은 **네이티브 Rust**입니다: ECDH 페어링 + 종단 간 암호화, 연결이 끊겨도 자동 재연결·재전송으로 패킷 손실 없음, 애플리케이션 계층 하트비트 유지와 가짜 온라인 감지, **화면 꺼짐 / 시스템 절전 유지**(디스플레이가 꺼져 있는 동안에도 전원 관리 어서션(power-management assertion)으로 연결을 유지하고, wall-clock 점프로 깨어남을 감지해 브리지와 봇이 몇 초 안에 재연결됨), 기기 연동 해제는 즉시 적용되며 해제된 App에 명확한 회신을 보냅니다.
- **그룹 채팅 / 다중 멤버 협업** — 멤버 라이브러리에서 AI 에이전트 팀을 구성하고(Claude / Codex / OpenCode / Kimi / Qoder 멤버가 계열별로 각자 모델, 사고 깊이, 아이콘을 가짐) 하나의 공유 대화에서 소통합니다: 오케스트레이터가 턴을 체인으로 직렬화하며(체인 내부는 직렬, 체인 간은 병렬, 멤버별로는 전역 직렬 — 파생된 릴레이 체인은 이미 대기 중인 멤버를 중복 제거하고, **모든 오케스트레이터 턴에 멤버 명단이 주입**되어 @멘션이 정확한 전체 이름과 일치해야 함), **멤버별 세밀한 긴급 중지** 또는 **전체 그룹 중지**(tombstone이 늦게 도착한 이벤트를 흡수)를 지원하며, 재시작 후에도 모든 것을 유지합니다(3-테이블 스키마, 숨은 작업 예외, 레이어-2 브레인 스왑 복구). **권한 드롭다운은 각 멤버의 CLI 계열에 맞게 적응합니다**(계열 네이티브 값 문자열로 저장 — 더 이상 codex / opencode / kimi 권한이 누락되지 않음), 실시간 이벤트 스트림은 40ms 창으로 병합되어 다중 멤버 동시성 버스트를 흡수하며, 어떤 상태에서도 create 항목이 정확히 하나만 존재하도록 영구 create 항목이 폴백으로 표시됩니다. 메시지는 스트리밍 분할 대화로 렌더링됩니다 — 사고 과정은 전용 필드로 빠지고(본문 텍스트에 사고 노이즈 없음), 버블은 멤버별로 접히며 도구 그룹 일괄 펼침을 지원하고, 버블 안의 @멤버 chip이 인라인으로 렌더링되며, 세그먼트는 도착 순서대로 인터리브됩니다. Composer는 두 섹션으로 나뉜 @-패널(멤버 / @all)과 통합됩니다. 전역 **설정 → 실험적** 섹션에 그룹 채팅 토글(기본 꺼짐)이 있습니다 — 이 섹션에는 **Hermes**와 **Pi** 두 실험 CLI 계열도 함께 들어 있습니다(전부 기본 꺼짐; Hermes와 Pi가 둘 다 꺼져 있으면 의존성 관리 패널이 해당 접이식 그룹을 숨깁니다).

### 대화 경험
- **리치 텍스트 메시지 버블** — Markdown 렌더링, 표, 코드 구문 강조, Markdown 미리보기.
- **마크다운 로컬 링크와 이미지** — AI 메시지 속 로컬 파일 경로는 인라인 **파일 chip**으로 렌더링됩니다(내부 상대 참조는 작업의 워크스페이스 기준으로 해석되고, 외부 절대 경로는 전용 `stat_path` 명령으로 존재 여부를 검사해 없으면 무효 링크로 처리되며, Codex 스타일의 `path:line:col` 링크 형식은 줄 / 열 접미사를 떼고 일반 파일 chip이 됩니다). 로컬 및 원격 이미지는 **버블 안에서 바로 렌더링**됩니다 — 클릭하면 라이트박스로 확대되고, 우클릭하면 원본 이미지를 복사할 수 있으며, 대화 컨텍스트 메뉴에는 대상 종류별로 나뉜 **이미지 복사 / 외부 파일 열기** 항목이 제공됩니다. 웹이 아닌 링크, `mailto` / `tel`이 아닌 링크는 모두 무효 처리됩니다 — 클릭 자체가 차단되어 로컬 파일 링크가 유발하던 앱 리로드 새로고침이 완전히 사라졌습니다. **Mermaid 다이어그램도 네이티브로 렌더링**됩니다 — AI 메시지 속 `mermaid` 펜스 블록이 클릭하면 라이트박스로 확대되는 라이브 다이어그램이 되며, PNG/SVG 내보내기를 지원합니다.
- **도구 호출 타임라인 카드** — Read / Write / Edit의 diff, WebSearch 결과 등이 연속된 타임라인 카드로 모입니다(연속 호출은 왼쪽 가장자리 선을 공유하고, 한 줄씩 펼쳐 상세를 볼 수 있음). 한눈에 들어오면서도 자리를 차지하지 않습니다. Codex 도구 호출도 동일한 의미론적 처리를 받습니다: `apply_patch`는 줄 번호가 포함된 Write / Edit / Delete 카드로 펼쳐지고, 읽기 전용 셸 명령은 휴리스틱으로 인식되어 Read 카드로 렌더링되며(PowerShell / cmd / bash 래퍼 형태 포함), 셸 카드에는 실행기 배지(python / node / …)가 붙습니다 — 이 모든 경우에도 원래 도구 이름은 그대로 표시됩니다.
- **대화형 질문(AskUserQuestion)** — UI에서 선택지를 바로 클릭해 답할 수 있고, 옵션에 마우스를 올리면 분할 페인에서 상세 내용을 미리 볼 수 있으며(클릭하면 미리보기가 고정되고, 좁은 패널에서는 위아래로 쌓이는 레이아웃으로 전환), '기타' 자유 입력과 **'먼저 상의하기' 항목**(답하기 전에 AI와 자유 형식 대화를 나눌 수 있으며, 공식 'Chat about this' 흐름을 그대로 재현)도 지원합니다. 대기 중인 승인 / 선택 카드는 이제 **앱 재시작 후에도 유지됩니다**(콜드 스타트 스냅샷) — 작업을 다시 열어도 이어서 답할 수 있고 유령 카드가 남지 않습니다.
- **AI 메시지 툴바**, 대화 속 링크는 시스템 브라우저로 열기, 작업 상태와 안 읽음 표시.

### 입력(Composer)
- **슬래시 명령 팔레트**(`/command`, **CLI 계열별 내장 카탈로그** — 큐레이션된 Claude 명령 20개 + 전용 Qoder 명령 22개 세트 — 설명은 인터페이스 언어를 따르므로 서로 다른 계열의 이름이 같은 명령이 섞이지 않으며, 팔레트는 올바른 범위 배지가 붙은 **워크스페이스 수준 스킬**도 집어내고 플러그인을 설치 / 제거하는 즉시 새로고침됨)와 **@ 파일 멘션 팔레트**, 인라인 파일 chip.
- **이미지 입력**, **작업별 독립 초안**, **모델 / 추론 강도 선택기**(Claude 로그인에는 **Fable** / Opus / Sonnet / Haiku 등급 내장, Codex 로그인에는 **Codex OAuth** 네이티브 등급과 minimal~xhigh 추론 강도 내장, OpenCode는 앱 내 **OpenAI 호환 공급자**를 재사용하고 작업마다 사고 깊이 선택 가능, Kimi 로그인에는 Kimi OAuth를 통한 네이티브 **K2.7 / K2.7 Highspeed / K3 / K3 [1m]** 등급이 내장되어 있고 앱 내 공급자 재사용도 가능하며, Qoder에는 **Auto / Ultimate / Performance / Efficient / Lite** 등급이 자체 추론 강도 선택기와 함께 제공되고, 모델 드롭다운은 현재 CLI 계열로 필터링), 사용자 지정 가능한 입력 툴바.
- **IME 안전 chip과 확대 가능한 이미지 chip** — chip 바로 옆에서 중국어 / 일본어 / 한국어를 입력해도 더 이상 IME 조합이 깨지거나 문자가 삼켜지지 않습니다: 제로 폭 렌더링 앵커와 커서 클램핑 덕분에 커서가 모든 chip의 안전한 쪽에 유지되고, 복사된 텍스트에도 그 제로 폭 문자가 따라붙지 않습니다. 이미지 chip은 사각 썸네일로 렌더링되며 **클릭하면 확대**할 수 있고, 제거 ✕가 더 이상 둥근 컨테이너에 잘리지 않습니다.
- **음성 상호작용(실험적, 기본 꺼짐)** — 초안 페인이 **음성 모드**로 전환될 수 있습니다(중앙 정렬 레이아웃은 유지되며, 첫 음성 메시지를 보내야 작업이 생성됩니다). 기본 깨우기 단어인 **'샤오마(Xiǎo Mǎ)'**(일반 IME와 같은 퍼지 세트를 사용해 퍼지 병음 허용으로 매칭)를 말하면 청각적 깨우기 응답이 울립니다. 음성 입력은 기기 내 STT(whisper, 언어 자동 감지)로 받아 적혀 일반 메시지로 라우팅됩니다 — 선택 / 승인 카드와 다중 선택 질문에 음성으로 답하는 것도 포함됩니다. 답변은 로컬 TTS 엔진(Kokoro / Melo / Matcha 중국어 음성 + fanchen-C / aishell3 순수 중국어 음성, ONNX 멀티 스레드 추론)이 코드 블록과 표를 건너뛰는 스트리밍 문장 분할기로 소리 내어 읽어 주고, TTS가 마이크로 피드백되지 않도록 에코 필터링이 적용되며, 답변과 승인 카드의 피드 읽기 및 완료 바 재생 버튼을 제공합니다. 음성 메시지는 **오디오 버블(AudioChip)**로 렌더링되며, 우클릭 메뉴에서 받아 적은 내용 펼치기, 내용 복사, 텍스트 숨기기를 할 수 있습니다. 모든 것은 전용 **설정 → 음성** 페이지(깨우기 단어 / 무음 타임아웃 / 모델 다운로드 / 음성 및 속도 / 마스터 스위치)에서 구성되고, 전역 **설정 → 실험적** 토글 뒤에 게이트되어 있습니다.

### 통합 개발 도구
- **통합 터미널** — xterm.js + PTY 기반의 진짜 터미널. 터미널 로그 속 링크는 클릭할 수 있습니다(왼쪽 클릭은 내장 브라우저에서 열기, 오른쪽 클릭은 시스템 브라우저 호출 또는 주소 복사). 오른쪽 파일 패널에도 **터미널 탭**이 통합되어 있습니다(상시 렌더링, 패널 열림 상태로 게이트, Windows Terminal 스타일 탭 바 — 비례 압축, 오버플로 화살표, 플로팅 선택 알약). 사이드바 / 터미널 패널 열고 닫기에 **200ms 슬라이드 애니메이션**이 적용됩니다.
- **파일 트리 사이드바 + 사이드 파일 패널 + Monaco 에디터** — 코드와 Diff를 탐색하고 확인합니다.
- **열린 파일 외부 변경 실시간 동기화** — 열려 있는 파일 탭이 상주 부모 디렉터리 watcher로 디스크를 계속 지켜봅니다(경로 필터 + 디바운스 집계): 파일이 앱 밖에서 수정되거나 삭제되면 탭이 즉시 반응합니다 — **외부 변경 충돌 다이얼로그**(외부 버전 불러오기 / 내 변경 유지), Monaco는 **최소 공통 접두사 / 접미사 편집**으로 리로드되어 커서와 실행 취소 스택을 보존하고, 외부에서 삭제된 파일에는 **취소선 탭 마커**가 붙고 `Ctrl+S`로 즉시 다시 만들 수 있습니다(전역 `Ctrl+S` 폴백은 사이드 패널 미리보기 파일도 커버하며 worktree 경로를 통과시킵니다).
- **리치 파일 미리보기** — 사이드 패널이 코드가 아닌 10종 이상의 파일 형식을 네이티브로 렌더링합니다: Office 문서(Word / PowerPoint / Excel)와 PDF, 정렬 가능한 표로 보여주는 CSV / JSONL / Parquet / SQLite, 이미지(AVIF / ICO 포함)와 오디오 / 비디오(asset 프로토콜로 스트리밍), 압축 파일 내용(zip / jar / tar / gz, 압축 해제 없이 탐색 가능), 임의의 바이너리를 위한 Hex 뷰어, 폰트 견본, SVG(렌더링 / 소스 토글), Jupyter 노트북까지 포함합니다. **Excel(.xlsx)은 셀을 그 자리에서 바로 편집할 수 있고**(셀 더블클릭, 수식 셀은 보호되며 저장하지 않은 변경 사항은 표시됨), 미리 본 파일은 무엇이든 **시스템 기본 앱으로 열기**도 가능합니다. **HTML/HTM 파일은 라이브 임베디드 미리보기**를 지원합니다 — iframe `srcdoc` + base 주입으로 상대 리소스가 파일이 있는 디렉터리를 기준으로 해석되고, 재귀 asset 디렉터리 허용 목록을 통해 서빙됩니다 — 텍스트 듀얼 모드 계열에 합류해 탭마다 **편집 / 미리보기 전환**(편집이 기본)을 갖춥니다. 미리보기는 **UI 편집 모드**도 갖췄습니다: 주입된 bridge 스크립트(기본 휴면)가 렌더링된 페이지 안에서 hover / 선택 / 드래그 / 인라인 편집을 가능하게 하고, 플로팅 설정 패널은 콘텐츠 / 스타일 / 속성 / HTML 4개 구역으로 나뉘며, eid 파생 패치 엔진이 편집을 **새로고침 없이** 소스에 바로 써 넣습니다 — 디바운스 커밋 파이프라인이 뒷받침하고 실행 취소 / 다시 실행을 지원합니다. 단독 **`.mmd` / `.mermaid` 파일**은 일급 문서로 열리며, 파일 전체 다이어그램 렌더링, 구문 강조, PNG/SVG 내보내기를 제공합니다.
- **파일 트리 다중 선택과 파일 작업** — 클릭 선택 / 드래그 박스 선택, 복사 / 잘라내기 / 붙여넣기(시스템 파일 클립보드에 연결되어 파일 탐색기와 상호 연동), 새로 만들기 / 이름 바꾸기 / 삭제, `Del`과 `Ctrl+C/X/V` 단축키 지원.
- **Git 워크플로** — 브랜치 전환, 변경 사항 Review 패널, 커밋 메뉴(✨ 원클릭 커밋 메시지 생성 포함), worktree 자동 감지와 추적. **Git 그래프 다이얼로그**가 커밋 히스토리를 시각화합니다(페이지화된 `git log --graph` 스캐너, 90% 뷰포트 스크롤 페이지네이션) — 브랜치 팝오버에서 들어가고, 아무 행이나 클릭하면 커밋 상세 패널이 열립니다. 초안 작업에는 **'새 Worktree' 옵션**이 있습니다: 워크트리가 먼저 생성되고(`wt-` 접두사로 자동 명명, `.git/info/exclude`에 등록되어 저장소를 오염시키지 않음), 그다음 작업이 여기에 바인딩됩니다. 파일 탭은 물리적 절대 경로로 중복 제거되고, 브레드크럼은 실제 워크트리 경로(`.codex/worktrees/<n>/…`)를 보여주며, 파일 chip은 작업 자체의 워크트리 루트를 기준으로 상대 경로를 해석합니다.
- **내장 브라우저 패널** — 오른쪽 패널에서 웹 페이지를 바로 열 수 있고, 멀티 탭과 작업 간 공유를 지원합니다. 문서를 찾거나 페이지를 미리 보는 데 앱을 떠날 필요가 없습니다.
- 현재 워크스페이스를 **파일 탐색기에서 열기**.
- **'열기'(OS 파일 연결)** — LoongCode가 시스템의 '열기' 후보로 등록됩니다(Windows는 NSIS 설치 프로그램, macOS는 `public.data` 문서 유형). OS에서 연 파일은 파일 패널로 들어오고, 앱이 실행 중이면 single-instance를 통해 이미 실행 중인 인스턴스로 전달됩니다(전달되는 인수 목록에서 앱 자체 실행 파일은 걸러집니다).

### 구성과 확장
- **Skills(스킬) / MCP 서버 / Plugins(플러그인) / 서브 에이전트(Subagents)**의 시각적 관리 — **Claude / Codex / OpenCode / Kimi / Qoder** 다섯 CLI 계열을 모두 아우릅니다(OpenCode는 태생적으로 Claude 스킬 루트를 공유하고, 관리형 `opencode.json`을 통해 MCP와 스킬 / 서브 에이전트 / 슬래시 명령의 켜고 끄기를 관리하며, Kimi는 자체 스킬 스캔, 사용자 / 워크스페이스 수준 MCP `mcp.json` CRUD(변경 시 하위 프로세스 자동 재시작 포함), **마켓플레이스에서 플러그인 설치**(설치 / 제거 / 켜기 / 끄기가 즉시 적용)를 갖추고, 서브 에이전트는 `AGENTS.md`로 관리하며, **Qoder**는 스킬 / 플러그인 / 서브 에이전트 / MCP 패널 전체에 자체 탭이 제공되고 모든 것이 `~/.qoder` 루트로 라우팅되어 Claude 설정과 섞이지 않습니다). 서브 에이전트는 **사용자 / 프로젝트 / 플러그인** 세 범위에서 보기, 새로 만들기, 편집, 삭제, 켜고 끄기를 지원합니다(플러그인 제공 항목은 읽기 전용).
- **메모리 관리** — 전용 설정 → 메모리 패널에서 앱을 벗어나지 않고 각 CLI의 영구 지시 파일을 목록으로 보고, 미리 보고, 편집하고, 새로 만들고, 삭제할 수 있습니다: Claude의 `CLAUDE.md`와 Codex / OpenCode / Kimi / Qoder의 `AGENTS.md`(전역 및 프로젝트별 모두), 그리고 Claude의 **자동 메모리(auto-memory)** 토픽 파일까지 검색 가능하고 자유롭게 이름 붙일 수 있는 컬렉션으로 모아 보여줍니다.
- **Hooks 설정** — Claude, Codex, Kimi, Qoder의 라이프사이클 Hook(도구 호출 전 / 후, 세션 시작 / 종료 등)을 UI에서 바로 보고, 추가하고, 편집하고, 삭제할 수 있습니다 — Claude와 Qoder의 사용자 / 프로젝트 공유 / 프로젝트 로컬 `settings.json` 계층(Qoder는 자체 `.qoder` 루트 아래)과 Codex / Kimi의 `config.toml`을 모두 아우르며, 알려진 필드는 구조화된 폼으로 다루고(인식되지 않는 필드는 원문 텍스트로 대체), 플러그인이나 관리 정책이 제공하는 Hook은 읽기 전용 통합 뷰로 볼 수 있습니다.
- **Model Providers(모델 공급자)** 구성으로 백엔드를 자유롭게 전환 — 흔히 쓰는 모델에는 **컨텍스트 윈도 공장 기본값**이 내장되어 있고, 모델을 새로 추가할 때 입력창 플레이스홀더가 권장값을 바로 알려줍니다(비워 두어도 합리적인 기본값 적용). 공급자마다 **네트워크 프록시**(시스템 따름 / 사용자 지정 / 끄기)를 독립적으로 설정할 수 있고, CLI 로그인 기반 공급자(예: Codex OAuth 릴레이, 또는 브라우저에서 디바이스 코드 페이지를 여는 **Qoder OAuth** 행)는 앱 안에서 **로그인 / 상태 / 로그아웃** 흐름을 제공하며, 로그인 명령을 수정할 수 있고 모델 카탈로그를 원클릭으로 새로고침할 수 있습니다. Claude 계열 공급자는 제시할 **인증 헤더**(`ANTHROPIC_AUTH_TOKEN` / `ANTHROPIC_API_KEY`)도 고를 수 있으며, 해당 환경 변수로 CLI 하위 프로세스에 주입됩니다.
- **의존성 관리 + 런타임 버전 관리** — 의존성은 정적 카탈로그에서 즉시 렌더링되며(항목별 설치 상태는 백그라운드에서 지연 감지), 필수 / 선택으로 나누어 보여줍니다. **필수 의존성인 Claude Code CLI와 Git은 앱 내 원클릭 설치를 지원**하고(Windows는 바로 설치 완료, macOS의 Git은 시스템 Xcode 명령줄 도구로 안내), **OpenAI Codex, OpenCode, Qoder CLI도 앱 내에서 원클릭 설치 / 업데이트**할 수 있습니다(네 AI CLI 중 하나만 설치해도 충분). `uv` / `pnpm`(및 `bun`)은 여러 버전을 나열 / 설치 / 제거 / 전환할 수 있고, 원클릭 폴백 설치도 지원합니다.
- **프록시 설정** — 단일 전역 스위치가 아니라 모델 공급자별로 설정합니다(위 참고); http / https만 지원합니다(SOCKS 미지원). 의존성 다운로드(CLI 설치 스크립트, `uv` / `pnpm` / `bun`)는 기본적으로 시스템 프록시를 따르며, 의존성별로 개별 재정의할 수 있습니다.
- **환경 변수 설정** — CLI 하위 프로세스(Claude / Codex)에 사용자 지정 환경 변수를 주입합니다(변경하면 하위 프로세스가 자동으로 재시작).
- **사용량 통계(Usage)** — 소비량을 직관적으로 확인합니다. Claude 또는 Codex OAuth로 로그인하면 실시간 사용량 배지(세션 / 주간 비율, 5분마다 갱신)가 사이드바와 해당 공급자의 로그인 카드에 표시됩니다(Codex 사용량은 실험적 토글로 켜야 하는 옵트인 항목입니다). 통계는 이제 **Claude / Codex / Kimi / Qoder 네 CLI 계열 전체를 아우릅니다** — CLI별 차원을 전환할 수 있고 동적으로 색칠된 차트와 모델 테이블(큐레이션된 12색 + 황금각 오버플로, 테마에 맞게 조정)로 표시되며, **캐시 토큰도 별도로 분리됩니다**: 모델 테이블에 총합 / 입력 / 출력 / 캐시 열이 이중 언어 라벨과 함께 추가되고, 총 토큰 카드에는 캐시 적중률 보조 행이 표시되며, 모델별 적중률은 캐시 적중을 따르고, 순위는 총합 기준으로 정렬됩니다(릴레이 / 중간 세션도 Codex 사용량에 집계). **히트맵 셀(일별)** 또는 **트렌드 포인트(모델별)**에 마우스를 올리면 입력 / 출력 / 캐시 적중 내역이 드러나고, 총 토큰 카드, 히트맵, 일별 트렌드는 모두 **캐시 읽기를 집계**해 모델 테이블의 열과 모든 수치가 일치합니다. **전역 계정 사용량 스위치**(설정 → 일반)를 끄면 기능 전체가 한 번에 꺼집니다: 사이드바 배지가 완전히 사라지고, 백그라운드 폴링과 수동 새로고침이 모두 멈추며, 공급자 카드의 사용량 블록에는 비활성화 안내가 표시됩니다 — 즉시 적용되며 재시작이 필요 없습니다. macOS에서는 백그라운드 사용량 / OAuth 상태 확인이 더 이상 시스템의 '다른 앱의 데이터에 접근하려고 합니다' 권한 팝업을 띄우지 않습니다.

### 데스크톱 경험
- **앱 전역 커스텀 우클릭 메뉴** — 대화 영역, 미리보기, 파일 트리, 작업 행, 사이드바 빈 공간 어디에나 상황에 딱 맞는 우클릭 메뉴가 있어 시스템 기본 메뉴를 대체합니다.
- **백그라운드 작업 표시줄 알림** — 창이 앞에 있지 않을 때(최소화 포함) AI 완료 / 실패 / 확인 요청이 뜨면 QQ / WeChat처럼 작업 표시줄 아이콘이 깜빡입니다.
- **새 작업이 지난 구성을 기억** — 새 작업 / 스킬이 지난번에 사용한 모델 공급자와 매개변수를 자동으로 이어받습니다.
- **네이티브 윈도 장식(macOS)** — macOS는 시스템 네이티브 Overlay 타이틀 바와 3색(빨강·노랑·초록) 버튼을 사용하고, 사이드바 헤더는 3색 버튼 아래 별도의 줄에 로고 / 워드마크를 배치하는 두 줄 레이아웃을 사용하고, 이를 위한 안전 영역을 확보하며, 노치 디스플레이의 전체 화면 안전 영역도 지원합니다. Windows는 테두리 없는 커스텀 윈도를 유지합니다.
- **테마와 배색 일관성('화선지·먹·금')** — 완전히 새로운 '화선지·먹·금' 비주얼 언어: 정성껏 조율한 세 가지 테마(다크 / 라이트 / 눈 보호 청람), 따뜻한 화선지 바탕 + 먹색 텍스트 + 화룡점정의 금색 인장. 콘텐츠성 제목에는 본명조(Source Han Serif) 세리프를 쓰고, 다크 테마는 배경에 옅은 금빛 광채를 더했습니다. 대화 영역, 입력 영역(종이 질감 플로팅 박스 + 원형 금인 전송 버튼), 작업 행(금색 책갈피 상태 스펙트럼), 설정 페이지(종이 카드 그룹), 파일 패널 / 터미널 / Monaco(gruvbox ANSI16)까지 전 영역이 일관되게 새 옷을 입었습니다. 앱 전체 배색은 통일된 테마 token 토대 위에 세워져 있어(역할 / 분류 팔레트 / 시맨틱 token, 라이트·다크 자동 적응) diff, 서브 Agent, Review, 사용량 경고, 봇 연결 표시등, 워크플로 상태, 모델 팔레트, 태그 패밀리 등 모든 장면이 색을 하드코딩하는 대신 token을 사용하므로, 테마가 달라도 일관된 외관을 유지하며 기본값으로 시스템 라이트·다크 설정을 따릅니다.
- **새로운 앱 아이콘 '우로보로스 원환 용'** — 짙은 먹빛과 금색의 둥근 모서리 사각 인장 배지: 제 꼬리를 물어 고리를 이룬 작은 용이 짙은 먹빛 바탕 위에 자리하고, 금빛 비늘이 화룡점정을 찍습니다. 앱 내 사이드바 logo는 세 가지 테마(다크 / 라이트 / 눈 보호 청람)에 따라 전환되며 각기 전용 배색을 보여주고, 눈 보호 테마의 워드마크는 같은 청람색을 사용합니다.
- **인터페이스 언어(중 / 영)** — 그래픽 인터페이스 전체가 중국어·영어 전환을 지원합니다. 기본값은 시스템 언어를 따르고 인식할 수 없으면 영어로 폴백하며, '설정 → 일반'에서 언제든 전환할 수 있습니다. AI 대화 내용은 영향을 받지 않습니다.
- **중 / 영문 설치 인터페이스**, 설치할 때 언어를 선택할 수 있습니다.
- **정보 페이지(About)** — 전용 설정 → 정보 페이지에서 앱 / 버전 정보, 6가지 상태를 보여주는 업데이트 확인 행, 라이선스와 개인정보 처리방침 전문 페이지(중 / 영, 인터페이스 언어를 따름), 후원 섹션(WeChat / Alipay QR 코드), 공식 저장소 링크가 달린 연락처 행(이메일 복사)까지 확인할 수 있습니다.
- **자동 업데이트 내장** — 실행 후 조용히 확인하고 업그레이드를 안내합니다.
- **신규 사용자 가이드(Onboarding Tour)** — 처음 써도 길을 잃지 않습니다.

## 🧩 의존성 및 원클릭 설치

LoongCode를 실행하려면 두 가지 **필수 의존성**이 필요합니다:

- **Claude Code CLI** — 모델 능력을 제공합니다(앱 자체는 Anthropic API를 직접 호출하지 않습니다).
- **Git** — 브랜치 전환, 변경 사항 Review, worktree 등 Git 워크플로를 구동합니다.

로컬에 아직 없어도 괜찮습니다. **명령줄을 손수 두드릴 필요가 없습니다**: LoongCode를 열고 **설정 → '의존성 관리'**에 들어가면 '필수 의존성' 그룹에서 설치 상태가 보이고, **'설치'**를 누르면 원클릭으로 설치됩니다.

| 필수 의존성 | Windows | macOS |
| --- | --- | --- |
| **Claude Code CLI** | 원클릭 설치(공식 설치 스크립트) | 원클릭 설치(공식 설치 스크립트) |
| **Git** | 원클릭 설치(포터블 PortableGit, 앱 디렉터리에 설치) | '시스템 설치 트리거'를 눌러 시스템 Xcode 명령줄 도구 설치 호출. 직접 `brew install git`도 가능 |

- 설치 과정의 로그가 실시간으로 표시되고, 완료되면 상태를 자동으로 다시 감지합니다.
- 프록시 환경에서는 이 패널에서 의존성별로 http / https 프록시를 따로 구성한 뒤 설치할 수 있습니다.
- '선택 의존성' `uv` / `pnpm` / `bun`도 원클릭 설치와 다중 버전 전환을 지원합니다.
- **OpenAI Codex CLI 선택 연동** — Codex 계열 작업을 쓰고 싶다면, 의존성 관리에서 **Codex CLI 원클릭 설치**도 지원합니다(공식 설치 스크립트 / GitHub 직접 연결 / 미러 가속 3가지 방식). 설정의 스킬 / 플러그인 / MCP / 서브 에이전트 패널에도 모두 Codex 차원이 제공됩니다.
- **Claude Code CLI 설치 소스 선택 가능** — 공식 설치 스크립트 / GitHub 직접 연결 / GitHub 미러 가속(미러 접두사 사용자 지정 가능). 일부 네트워크 환경에서 공식 소스에 접근할 수 없는 경우에 대비합니다.
- **Git 설치 소스 선택 가능(Windows)** — GitHub 직접 연결 / 미러 가속(미러 접두사 사용자 지정 가능). 포터블 PortableGit은 네트워크가 제한된 환경에서도 무리 없이 설치됩니다.

> ⚠️ 앱이 대신해 줄 수 있는 것은 CLI를 **설치**하는 것까지이며, **로그인은 직접 완료해야 합니다**: 통합 터미널에서 `claude` / `codex`를 실행해 안내에 따라 로그인하거나, **설정 → '모델 공급자'**에서 백엔드를 구성하세요.

## 🚀 빠른 시작

1. **의존성 준비** — Claude Code CLI와 Git을 설치하고 CLI에 로그인합니다(Codex 계열 작업을 쓰려면 Codex CLI도 설치). 아직 없다면 먼저 LoongCode를 열고 **설정 → '의존성 관리'**에서 원클릭으로 설치해도 됩니다.
2. **LoongCode를 설치하고 엽니다**.
3. **워크스페이스 추가** — 프로젝트 디렉터리를 지정합니다.
4. **새 작업 만들기** — 요구 사항을 입력하고 Enter를 누르면 세션이 시작됩니다(입력 바에서 Claude Code 또는 OpenAI Codex를 선택할 수 있음).
5. 오른쪽의 **터미널, 파일 트리, Git Review**로 변경 사항을 따라가고, 설정에서 필요에 따라 **MCP / 플러그인 / 스킬 / 모델 공급자**를 연결하세요.

## 🔄 자동 업데이트

LoongCode에는 [Tauri Updater](https://v2.tauri.app/plugin/updater/)가 내장되어 있습니다. 앱은 이 저장소의 릴리스 소스에서 업데이트 매니페스트를 가져옵니다:

```
https://github.com/LoongCode0/loongcode-release/releases/latest/download/latest.json
```

새 버전이 감지되면 사용자에게 알리며, Windows에서는 passive(무음) 설치 모드를 사용해 업데이트 과정이 거의 느껴지지 않습니다.

## ❓ 자주 묻는 질문

**Q: 로컬에 아직 Claude Code CLI나 Git이 없는데, 꼭 손으로 설치해야 하나요?**
A: 아닙니다. LoongCode를 연 뒤 **설정 → '의존성 관리'**에 들어가 '필수 의존성'에서 '설치'를 누르면 됩니다. Windows에서는 Claude Code CLI와 Git 모두 바로 설치되고, macOS에서는 Git이 시스템 Xcode 명령줄 도구 설치를 호출합니다. Claude Code CLI를 설치한 뒤에는 로그인을 잊지 마세요.

**Q: 설치했는데 대화가 안 되거나 모델 응답이 전혀 없나요?**
A: LoongCode에는 자체 모델 능력이 없으며, 로컬의 CLI 도구에 의존합니다. 해당 CLI가 설치되어 있고 PATH에 있으며 로그인이 완료되었는지 확인하세요: Claude 작업에는 `claude`, Codex 작업에는 `codex`가 필요합니다.

**Q: 회사 네트워크에서 프록시를 써야 하는데 어떻게 하나요?**
A: 앱 설정에서 http / https 프록시를 구성하세요. 단, 실행되는 CLI는 http/https만 지원하고 SOCKS는 지원하지 않습니다.

**Q: 업데이트 확인에서 새 버전을 찾지 못하나요?**
A: 자동 업데이트는 이 저장소 Releases의 `latest.json`에 의존합니다. 네트워크에서 GitHub에 접근할 수 있는지 확인하세요.
